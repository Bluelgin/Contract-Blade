# 赤月：酒红叠裙版

依据用户确认的 `approved-concept.png` 制作；实际模型截图在 `views/`，不是生图。

酒红外襟与暖粉白内褶裙独立构造，斜向开口绕入两侧及背面。第二轮将每个裙摆骨骼扇区分成两片具有实际凹凸的折面，加入独立加厚织锦包边与金绳、裙角金坠；暗色外褶衬面和浅色内衬遮挡运动中的折缝。奶白袖身配酒红袖口及凸出的内袖翻边；赤金头侧花结、立体腰绳环、错落垂绳与金坠增加层次，保留深色垂襟。不是仅以贴图绘制褶皱。

保留原粉白头发与单尾、脸部、袜子鞋子、原骨骼层级及全部外部动画。不恢复月轮、专属武器或专属剑舞。原工程备份为 `before.bbmodel`。

静态工程：`akatsuki-crimson-wrap.bbmodel`；女仆运行资产：同名 `.geo.json` 与 `.png`。模型包构建器使用这些资产，黑白狐不变。YSM 发布包本次未更新。

复现：在当前女仆适配基线的副本中，按顺序执行 `setup.js`、`build.js`、`details.js`、`lining.js`、`layered-finishing.js`、`review.js`、`save.js`。这些脚本只通过 Blockbench MCP 执行，不能直接用 Node 执行。恢复脚本只加载隔离的基线，不覆盖旧工程。上一轮发布资产另存于 `revision-one/`，可用于回退和对照。

第三轮修正悬空饰物：头结增加贴合发束的固定座，垂带分段顺着发束折转，金端与末段连续；饰物绑定到既有 `RightSideHair`，与接触的发束同步。腰绳环缩小前向间距，垂绳沿真实外裙截面分段，使用既有 `FM/FM1` 裙骨骼，末端金坠沿绳方向连接，避免刚性腰部垂带和动态裙面各自运动。该轮前的工程及两个模型包备份在 `revision-two/`。近景截图为 `head-attachment.png` 与 `waist-attachment.png`。

验证：615 方块（第二轮 608，第一轮 442，原 395）、179 骨骼、单张 512×512 贴图。增加方块是折面、衬层及边饰，未增加骨骼、材质或每帧脚本。保护部件的几何、UV 与采样像素不变，无越界 UV。更新后完整 185 动作重新采样 5072 帧，无非数值变换，统计见 `adapted-preview-scan.json`；走跑、坐下、游泳、爬梯、使用弓盾、拔刀、睡觉的 10 张截图已重做。真实 TLM 几何构建、185 个默认加覆盖动作的严格解析、前一版模型包的可恢复升级及 Gradle 构建已在更新资产后通过。未做帧率实测，不声称比第一轮更省性能。

边界：这些检查不等同于游戏内视觉验收，也不复现本体控制器混合、家具和手持物品、真实 YSM 弹簧过程。尚未宣称所有动作零穿模或性能提升；测试端需要进一步验收。
