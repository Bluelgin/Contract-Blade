# 赤月 B：另一侧酒红斜襟衔接

以上一版 `../midnight-b-side-polish/akatsuki-b-side-polish.bbmodel` 为基础，局部重建另一侧酒红斜襟本体，而非只缩窄红衬。此前修好的黑色月纹外襟完整保留。

酒红外襟的外侧下缘由 x=-8.55、z=-4.18 收到 x=-6.65、z=-1.62，形成由正面包向侧面的折面，不再整片保持相同前伸深度。外侧落点由 y=10.3 调至 y=8.85，减小与黑色侧袍之间的过早截断。中部衣片向外避让底层黑袍，减少静态穿插；金边跟随新的分段边缘，红衬仍是窄卷边。

仅替换原酒红斜襟、配套金边和窄红衬共 12 个方块，新建 16 个。最终 416 个方块，179 个原骨骼，单张 512×512 无损重排图集。尾巴、头、手、袖子、月轮、原动画及上一侧修订均不变。

`akatsuki-b-both-sides.bbmodel` 是独立可编辑版本，另有同名 `.geo.json` 和 `.png`；旧版及游戏资源没有覆盖。两侧正侧面、斜侧面与近景均为原生模型预览。

`validate.cjs` 核对保存后的原骨骼/动画、保留几何/父级/可见性、未修改面的纹理取样、静态骨骼补偿和 Bedrock 导出。视觉已检查静态多角度，但未进行游戏内动作和衣物物理测试，不能据此保证运动中无穿插。预览临时隐藏独立狐形态，保存文件保留原可见性。原资产许可与署名不变。
