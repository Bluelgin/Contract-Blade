# 赤月 · B 完整衣袍重构

本次以 `midnight-b-both-sides/akatsuki-b-both-sides.bbmodel` 为基线，对照已批准的 B 五视图推进衣服部分。此目录是独立版本，未覆盖外部模型包或接入游戏。

## 已完成

- 从腰到下摆重新构造展开的侧后袍，前斜襟和两侧共用衔接端点，裙摆轮廓不再是窄直片。
- 酒红斜襟为四个真实折面拼成的宽叠襟；对面的月纹黑襟为三个折面，下方增加内卷红衬。
- 两侧、后袍为连续分片，使用有高低变化的裙脚，配酒红至墨紫的局部染色。
- 内裙为十二个前部凹凸褶面，并延续到侧后部；褶脚有错层，不再共用一条齐平底边。
- 裙边金饰直接绘制在服装折面上，避免额外金边杆互相穿插；加宽下摆饰边并补顺斜襟方向的金枝纹。
- 外搭领采用实体交叠衣片，保留米白内领并拓宽搭领下端。

## 保留与检查

432 个模型块（基线 416），179 个原有骨骼，单张 512×512 贴图。头发、耳朵、面具、尾巴、袖子、手、月轮及原动画未改；未新增骨骼。保留旧版本。

`validate.cjs` 验证了保留元素的几何、骨骼父级、动画、可见性一致，并对原有贴图面进行了 529920 次像素采样一致性检查。Bedrock 静态导出通过；新衣片的静止姿态世界坐标和旋转误差在容差内。

这是实际原生模型，不是生成式渲染替代品。已检查正面、斜侧面、两侧和背面预览。概念图包含光照及推断的背部，不宣称逐像素相同；游戏内动画穿插、移动时衣片衔接和性能还需运行验证。月轮按要求保留原状，后续单独完善。
