# 赤月 B 保形性能优化

基线：`../midnight-b-full-robe/akatsuki-b-full-robe.bbmodel`。独立另存优化版本，原版保留，未覆盖外部模型包或接入游戏。

## 优化结果

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 模型块 | 432 | 432 |
| 骨骼 | 179 | 179 |
| 有效面 | 2252 | 1943 |
| 常规三角形等价数 | 4504 | 3886 |
| 贴图分辨率 | 512×512 | 512×512 |
| PNG 文件 | 152917 B | 103707 B |
| 几何 JSON 文件 | 229153 B | 144525 B |
| 可编辑模型文件 | 570130 B | 505924 B |

去掉 187 个全透明 UV 面、55 个完全埋在不透明同骨骼实体中的面，以及 67 个同骨骼下被不透明实体覆盖的接触面，共 309 面（13.72%）。不跨骨骼裁剪：保留可能在动作中露出的裙摆、红衬、头发和尾巴结构。未删除或合并模型块，所有几何、父级、骨骼、动画和原可见性保持一致。

贴图重排只合并完全相同的像素块，不缩放；PNG 使用非调色板无损编码，未量化颜色。贴图文件缩小约 32.2%，但 GPU 解码后的 RGBA 基础占用仍为 1 MiB。几何 JSON 压缩排版减少磁盘体积，不单独视作渲染提速。

## 验证范围

`validate.cjs` 独立验证了 309 个裁面依据和 801156 次保留面贴图采样；保留像素一致。导出的 per-face UV 共 1943 面，与编辑器结果一致。检查了本地 TLM 1.5.3 的 SimpleBedrockModel 加载器：缺省面 UV 会设置 emptyFacesMask，绘制时跳过对应顶点提交，优化不只是隐藏编辑器面。

九个 800×1100 固定角度原生预览共 792 万像素：六个角度完全一致，其余三个角度合计 5 个像素有微小差异（详见 `preview-comparison.json`）。该检查不是完整动画或游戏运行测试；未测试实际帧率，不把 13.72% 面数降低宣称为等幅 FPS 提升。骨骼动画计算量与模型块数量未降低。

文件：`akatsuki-b-optimized.bbmodel` 可编辑源文件；`akatsuki-b-optimized.geo.json` 静态几何；`akatsuki-b-optimized.png` 配套贴图。`before/` 与 `after/` 保存固定视角预览，`culling-report.json` 记录全部裁面依据、验证结果和体积对比。
