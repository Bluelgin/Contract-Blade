# 赤月 · B 衣装结构重构

本版替换上一轮的裙子、前襟、胸身和腰封，保存为独立模型；没有覆盖原模型、外部模型包或游戏资源。

## 实际改动

- 收窄腰封至 7.26 单位，酒红搭领延伸到腰封内，月扣和细绳置于衣服前面。
- 重建向下展开的侧后袍。宽酒红前襟采用纵向折面，替代先前逐段加宽的横向板条。
- 黑襟下缘斜切，追加翻角、卷回折面与酒红反衬；另一侧前襟也有错层红衬与金边。
- 内裙改为十个交替前后深度的褶面，并加强凹凸面的明暗。
- 米白肩衬、实体交领、酒红搭领和实体细翻边重新连接。
- 放大并移动黑襟月纹，按折面重绘酒红至黑紫的块状浸染，以及短而零散的金枝纹。

仍保留头、头发、手、袖子、尾巴、狐形态和原有月轮，不新增骨骼或修改动画。

## 原生文件

- `akatsuki-b-reconstructed.bbmodel`：可编辑模型。
- `akatsuki-b-reconstructed.geo.json`：Bedrock 兼容导出。
- `akatsuki-b-reconstructed.png`：单张 512×512 无损重排图集。
- `preview-front/angle/side/back.png`：最终图集重排后的原生模型预览，800×1100。
- `structure-front/angle/side/back.png`：无纹样材质的结构检查预览。
- `changes.json`：改动范围及独立校验结果。

408 个方块、179 个原骨骼。服装使用有厚度的原生方块折面与透明轮廓裁边，附加实体滚边；这不是任意网格，也不是仅重涂旧裙子的贴图。实体交领不依赖透明裁边。袖子沿用前版，不能把“完整推进衣装重构”解释成每个原有部件都重新建了一遍。

校验：未改动方块的几何、父级、可见性和 512000 次逐面纹理取样一致；骨骼及动画数据一致；新衣片静态骨骼变换补偿通过；导出尺寸及图集一致。校验不证明视觉与参考完全一致，也不证明游戏内物理摆动无穿插。没有运行游戏内验证。

## 与参考的边界

参考是带柔光的生成概念图，不是可直接还原的精确三视图。当前原生衣装完成了本轮结构、配色和纹样迭代，但不能宣称像素级一致：原生方块布料、折面和像素裁边的观感更硬；原有头尾比例与参考不同；头后月轮按用户此前要求暂缓调整。本版侧背面保留原始尾巴，没有依据生成图删尾巴。

预览临时隐藏独立狐形态，保存文件已恢复原可见性。沿用赤月原资产的许可证与作者署名，不变更资产授权。
