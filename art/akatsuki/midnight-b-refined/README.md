## 衣装修订

- 重新包覆的侧袍和后袍，十二面酒红内褶裙；内裙露出更多，外袍背面为酒红衬里。
- 宽酒红斜襟，七段向下展开，末端逐渐外翻；衣片本身从酒红浸染至黑紫，取消原先的窄红条。

- 横向黑红分层腰封、放大的月形腰扣；去掉大方块蝴蝶结，换成细红绳和金色流苏。
- 米白交领和肩衬、酒红外领，替换旧胸前细白线。
- 重绘月纹、枝纹和袖上金纹，并补充衣片褶皱明暗和黑紫浸染。

## 文件与边界

`akatsuki-midnight-b-final.bbmodel` 为可编辑源文件，`akatsuki-midnight-b-final.geo.json` 为 Bedrock 兼容导出，`akatsuki-midnight-b-final.png` 为单张 512×512 图集。纹理无损重排，未降采样未改动的原贴图。

总计 395 个方块、179 个原骨骼；没有新增骨骼或编辑动画。新衣片挂接原骨骼，并补偿静态骨骼角度。头、手、尾巴、狐形态与头后的月轮不变；月轮按用户要求后续再处理。

`materials.js` 负责材质绘制，`rebuild.js` 负责衣片结构和骨骼挂接，`validate.cjs` 独立核对保存文件。校验覆盖未改动区域的逐面纹理取样、几何与父级、骨骼和动画、静态挂接位置、衣片关节连接和 Bedrock 导出。结果在 `changes.json`。

所有预览均为 Blockbench 原生模型截图，截图临时隐藏狐形态，不改变保存文件的原始可见性。本版尚未覆盖游戏模型包，也尚未进行游戏内运动状态验证。沿用原赤月资产的许可和署名信息，不修改原资产授权。
