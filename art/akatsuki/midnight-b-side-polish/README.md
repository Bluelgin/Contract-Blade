# 赤月 B：侧袍收缓

在 `../midnight-b-reconstructed/akatsuki-b-reconstructed.bbmodel` 上局部修订，上一版和外部游戏模型包不覆盖。

原侧面问题：月纹外襟下端先大幅向前伸，再跨较大距离折回，形成明显硬尖角；另一侧的红衬也跨度偏大。新版本将月纹外襟下部顺着侧身包覆，拆成衔接折面；取消大折返，红衬仅向后收 0.26～0.55 单位、下落 0.57～0.66 单位。另一侧红衬缩为窄卷边，去除多余滚边尖端。接袍边增加深色布边，侧后衣片背面的露红改为深色，红色留在实际下摆衬里上。

只替换 12 个衣片/滚边方块，新增 16 个；保留方块的几何和父级均不变。另有 8 个侧后衣片仅调整背面颜色，透明轮廓保留。尾巴、头、手、袖子、月轮、179 个骨骼和动画不变。最终 412 个方块，单张 512×512 图集，无损重排。

`akatsuki-b-side-polish.bbmodel` 为可编辑源文件，另附对应 `.geo.json` 和 `.png`。`preview-side-detail.png` 为实际原生侧面近景，另有 front / angle / side / other-side 预览。

独立校验保留几何/父级、骨骼/动画、未修改面的纹理采样、静态骨骼补偿和 Bedrock 导出。未进行游戏运动状态验证，不能据此保证动作下没有穿插。预览临时隐藏独立狐形态，保存文件恢复原有可见性。授权与署名沿用原赤月资产。
