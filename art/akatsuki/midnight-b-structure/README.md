# 赤月 B：裙装结构重构

本版纠正上一版仅改衣服贴图的问题，保留上一版作为历史版本。主文件为 `akatsuki-b-structure.bbmodel`，游戏兼容导出为 `akatsuki-b-structure.geo.json`，单张图集为 `akatsuki-b-structure.png`。

旧裙装 36 个方块全部替换为 29 个新的裙装结构方块：十面酒红内褶裙、分开的墨色侧袍与后袍、前左开襟、七段向下加宽的斜向叠襟、独立连续的酒红衣片、几何金边与腰内承托。斜边由实际旋转的衣片构成，并非在原直筒裙上画斜纹。裙摆分别具有短内裙、斜向前摆和更长外袍的层次。

新衣片挂接原有裙装骨骼，并补偿骨骼初始旋转，使静态位置不会被旧骨骼角度推偏。未新建骨骼、未编辑动画；总方块数 400，原骨骼数 179。头部、手、尾巴、狐形态和头后的月轮不变。

图集无损重排后仍为 512×512，未降低原贴图分辨率。`validate.cjs` 核对非裙装几何、父骨骼、逐面纹理取样、骨骼属性、动画和 Bedrock 导出；结果写入 `structure.json`。

预览为 Blockbench 原生实模，而非生图。源文件保留狐形态可见性，截图暂隐藏狐形态方便查看人形。此版尚未替换游戏模型包，尚未完成游戏内运动状态验证。头后月轮按用户要求留待后续处理。
