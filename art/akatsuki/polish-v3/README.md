# 赤月 · 醉月衣纹 v3

独立的 Blockbench 原生可编辑预览，源于 v2，未覆盖原模型，未接入游戏或发布包。

单侧墨黑裙片加入暗红残月、旧金断续勾边与低反差流云；两袖添加淡酒气曲纹。复用原腰饰和发饰，绘制旧金残月、深红内芯与小月纹发饰。两个短红绳方块挂在原腰饰骨骼，使用衣片真实渲染表面测量静态贴合，不新增骨骼。

贴图依旧 256×256。新增纹理只占用当前无引用的区域，原被引用像素保持不变，避免影响手部、手环、面具、头发、尾巴和隐藏狐形态。现有方块位置、尺寸及所有骨骼、挂点和动画保持不变；方块总数从 405 变为 407。新增几何的实际游戏内性能和动态衣饰交互尚未测试。

工程包含原始可见性。Blockbench 预览临时隐藏了独立狐形态，以便检查人形；导出工程保留该形态。

`validate.cjs` 检查现有几何、骨骼、动画、无关 UV、嵌入贴图与红绳中心表面接触。`validation.json` 记录原生绘制及独立验证结果。正面、侧面和近景截图用于美术审阅。
