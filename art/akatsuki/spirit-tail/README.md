# 赤月 · 灵尾

赤月的玩家外观模型，包含黑红服饰、银白长发、头顶狐耳、戴头盔时展开的三条灵尾，以及第三人称持剑挥动时出现的「暗红斜月」。

将 [contract_akatsuki](contract_akatsuki) 整个目录复制到游戏实例的 `config/yes_steve_model/custom/`。更新已有安装时，请先移走同名的旧目录或旧 ZIP。安装说明和署名随模型附带。
