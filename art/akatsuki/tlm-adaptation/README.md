# 赤月 × 车万女仆本体动作适配

基准：Touhou Little Maid 1.5.3 / Forge 1.20.1，本机原始赤月角色包 + 当前粉白无月轮模型。不是重做专属站姿、专属武器或专属攻击。

## 已完成

- 按本体真实缺省补全顺序合并原角色包动作，审查完整 185 个片段：移动/生活状态 43、持物/使用/挥动 56、枪械 45、施法 19、乐器 22。
- 20 处旧名称映射到当前骨骼。41 处不存在的旧部件轨道从相应覆盖片段中去除，已有目标轨道优先，不创建多余几何。
- 坐下、棋盘、野餐、椅子、电脑、键盘、读书和乘船动作改用连贯收拢的裙摆；游泳调整裙摆和尾巴；爬梯调整裙摆避让，保留抬腿动作。
- 5 处垂直速度归一化表达式加入零值保护。
- 当前几何、UV、贴图、袜子保持不变；未恢复月轮和撤回的专属剑舞。静态模型仍为 395 个方块、179 根骨骼、单张 512 × 512 图集。

## 文件与使用

`akatsuki-tlm-adaptation-preview.zip` 是独立的本地预览角色资源包。手动放入 Minecraft 的 `resourcepacks` 并在游戏中启用即可，不需要修改契约之刃代码。它沿用原包模型 ID `akatsuki_winefox:akatsuki`，请避免同时启用另一份相同 ID 的赤月包，以免资源优先级混淆。这里没有安装或覆盖测试端资源包。

`akatsuki-adapted.bbmodel` 为静态编辑工程；游戏使用外部动画文件。`akatsuki-motion-review.bbmodel` 为合并了 185 个动作的查看工程，不应当直接作为游戏动画导出来源。第三个动画文件 `akatsuki.adaptation.animation.json` 仅存放 52 个需要覆盖的动作，原先两个动作文件保持原样。

`contact-sheets` 是 185 个片段各一帧的原生模型预览，分为 14 张。`all-poses` 是每个片段的单独图片。`before` 用于对照旧版；`after` 和 `ladder-trial*` 是已弃用的中间尝试，不是最终效果。`coherent-skirt`、`final-ladder` 对应最终坐姿和爬梯规则。

## 验证及边界

使用本机真实 TLM 几何构建器和严格 Molang 动画解析器验证 185 个片段、2359 条骨骼轨道、1001 个表达式，骨骼与装备挂点检查通过。资源包按实际加载顺序合并后的结果与验证版本完全一致。

Blockbench 共采样 5072 帧，无非数值变换，并检查了上述 14 张动作预览表。测试使用健康状态及明确的持物、视角和速度输入；YSM 二阶弹性运动使用稳定输入近似，不模拟真正的弹簧过程。

尚未进行游戏内视觉验收。预览不显示实际手持物品/家具，也不复现本体控制器的多动作混合、真实弹性、过渡、家具定位和所有伤血状态；因此不能据此保证所有时刻零穿模。长裙在极端抬腿/蹲伏时仍需游戏复查，尤其是爬梯、椅子、乘船、趴卧和双手装备。后续重点测走跑 + 持物、坐姿 + 交互、弓/弩/盾/拔刀剑、上下梯和低血狐形态。

以上是当前版本的完整片段清单，不涵盖其他模组今后额外注册的新动作。
