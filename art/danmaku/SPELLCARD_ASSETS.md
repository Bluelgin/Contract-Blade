## GUI 接入约定

- `wheel_base` 是无文字、无图标的透明外缘底图；中央暗紫区域保留给真实物品，不使用简化御札代替。整个底图可按 GUI 比例缩放。
- 256px 设计坐标：中心 `(128,128)`；四个 32px 图标左上角分别为灵针 `(112,40)`、散华 `(184,112)`、护身 `(40,112)`、幻想 `(112,184)`。分区沿两条对角线，与现有轴向选择方向一致。
- 真实御札示例区域为 `(104,104)` 起的 48px 方框；此为展示比例，游戏开发者可用 renderItem 对齐到中心。
- 名称、等级、费用等文字由语言文件与 GUI 代码负责，不烘焙文字。
- 未选中仅画基础图标；悬停／选中时在图标中心叠 `selection`，可用普通 alpha 调节、轻旋转；锁定降低图标亮度／饱和度并叠加独立 `lock`。锁定不只靠颜色辨认。
- 美术资源提供全部状态；整合分支的 GUI 行为见代码接口文档。具体绘制顺序：底图 → 状态光环 → 符式图标 → 锁标 → 真实物品 → 本地化文字。

## 战斗特效接入约定

所有效果使用常规透明混合，无 Shader 依赖。颜色已经写入纹理，默认白色顶点色即可。
灵针朝向为贴图上方（负 Y），锚点为中心；`seal_needle` 沿飞行方向旋转，轻光尾已包含在剪影中。
`seal_flower` 用于五瓣花符，`petal` 可复用为外绽／回收花瓣；收束高光可少量复用 `intercept_flash`。
`seal_guard` 是纯空心护环，不带永久闪光；拦截时只在命中位置短暂叠加 `intercept_flash`。

`fantasy_layers` 为 128×128 图集，每格 64×64，UV 像素坐标如下：

| 花阵层 | UV 左上角 | 尺寸 |
| --- | --- | --- |
| 绯红外阵 | (0, 0) | 64×64 |
| 紫色次阵 | (64, 0) | 64×64 |
| 金色内阵 | (0, 64) | 64×64 |
| 樱粉心阵 | (64, 64) | 64×64 |

以各格中心为旋转锚点，四层错位旋转、向中心缩放收束；末段叠空心 `final_seal`。图集格内留有透明边距，避免采样串格。不要把整张图集作为一张四花贴图绘制。
建议每层保持 0.35–0.65 的整体 alpha，错开闪光时刻；小画质保留绯红外阵和金色内阵即可，其余层可由代码按画质选择。以上是美术整合建议，不是新增运行时配置。
护环中心 18×18 区域全透明；每层花阵中心 10×10 区域全透明，符印不画不透明圆盘。

分镜顺序：护身显印 → 展开 → 局部拦截 → 淡出；幻想四阵展开 → 错位旋转 → 向内收束 → 终印消退。**分镜不定义战斗时序、伤害、次数或十级解锁规则。**

用户确认采用「朱樱封札」像素第二稿：以长符纸、樱花契印、纵向符纹为主体，小绳结与侧铃为点缀。参考本模组像素轮廓及分级明暗，不复刻其他饰品的大蝴蝶结造型。

- `manka_talisman.svg`：32×32整数网格原创矢量源，含40步离散SVG动画，无位图嵌入。
- `export_manka_animation.py`：直接按32像素导出至正式游戏资源，无大图缩小、无平滑模糊；`--check`逐像素复现且不写正式文件。

- 局部契印/纸光缓慢明暗变化，金铃及短流苏一像素轻摆；纸张主体不晃动。首帧与确认的第二稿像素一致。
- [循环预览](previews/manka_item_pixel_loop.gif)：离线贴图动画预览，不是实机录像。

正式物品路径与模型引用未变，物品栏和轮盘中央原生renderItem自动使用新动画，无需修改Java。资源清单记录本次批准的SHA-256；14张轮盘/符式特效贴图保持不变。验证接缝不大于普通帧间变化。

## 可复现导出与验证

依赖 Python 3.10+、Pillow 12.3.0、Inkscape 1.2.2；预览文字额外使用 DejaVu Sans。
从仓库根目录运行：

```bash
python art/danmaku/export_manka_animation.py --preview
python art/danmaku/export_manka_animation.py --check
python art/danmaku/export_spellcards.py
python art/danmaku/export_spellcards.py --check
python art/danmaku/preview_spellcards.py
```

导出器将 SVG 渲染为目标原尺寸 PNG，统一 RGBA 并移除渲染器机器信息；检查模式在临时目录重新导出，与正式 PNG 逐像素比较，不写正式目录。
`spellcard_assets.json` 为权威资源清单；`spellcard_validation.json` 为尺寸、路径与校验值记录。
检查覆盖源稿禁用嵌图／文字／外链、清单完整性、透明通道、透明边距、图集四格边界、中心留空以及御札动画约束。
导出器只允许写此清单中的静态 PNG 与本目录验证报告，不修改 Java 或原御札。
