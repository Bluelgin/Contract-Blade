# 黑白狐模型包图标

The runtime pack uses `fox_pixel_icon.svg`, a hand-authored pixel icon showing
two fox animals. `fox_pixel_icon.png` is its raster export and
`fox_pixel_icon_preview.png` is a larger preview. The character textures are
unchanged from the supplied model pack.

`interwoven_foxes.png` is an earlier image-generation concept, not the runtime
icon. No original character textures were generated or edited.

Generation prompt:

Use case: stylized-concept. Asset type: square Minecraft Touhou Little Maid custom model-pack icon. Create a polished stylized pixel-art illustration of exactly two adorable three-tailed fox animals, one silver-white fox with warm red accents and small pale gold forehead crown, and one ink-black fox with muted violet accents and small dark gold forehead crown. They curl around one another in a harmonious interwoven circular yin-yang-like composition, their flowing three tails entwining, both distinct faces clearly visible, fluffy pointed ears and cute calm expressions. Bold readable silhouettes, large clean pixel clusters, restrained soft shading, charming Japanese fantasy game aesthetic, elegant not busy. Fill most of the square with the pair, safe outer margin. Solid very dark desaturated blue-purple background with clear contrast for both foxes. Designed to remain recognizable at a tiny 64x64 thumbnail. No humans, no swords, no lettering, no logos, no watermark, no extra foxes. Square image.

The runtime archive is a derivative of the supplied 1.0.0 pack, not a replacement
for the editable final Blockbench projects in the artist's workspace. Run
`python tools/build_fox_model_pack.py` to reproduce the scoped archive changes.
