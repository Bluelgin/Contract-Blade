## 性能优化副本（当前最新）

`fox_*_optimized.bbmodel` 从接触修正版另存，不覆盖美术原稿。动画、骨骼、装备挂点、方块位置尺寸及隐藏形态保留。

- `optimize-texture.js` 将引用的纹理片段按完整 RGBA 内容去重，纯色面共享纯色采样，并为每片保留一像素边缘扩展。保留非纯色片段的原像素和 UV 方向，使用矩形装箱重排，双狐均由 1024² 收至 512²，没有缩小纹样。每张基础 RGBA 层理论存储由 4 MiB 减至 1 MiB；这不是游戏显存或 FPS 实测。
- `optimize-faces.js` 仅在白狐正常不透明外观下，去除同一骨骼内、四角严格位于另一完整不透明方块内部的面；白狐删除 93 面（186 个理论三角形）。保留所有方块与骨骼。黑狐因 Boss 透明渲染而完全跳过删面。
- `optimize-review.cjs` 检查全部方块变换、骨骼、动作及可见性不变，未删除面的 UV 方向和 RGBA 采样相同，核对超过 535 万个采样点。报告为 `optimized-verification.json`，正面效果为 `optimized-preview.png`。
