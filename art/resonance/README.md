# Resonance item art

Concept: built-in imagegen, stylized-concept, transparent sheet of a small amethyst core, a flowing partial crystal ring, a complete luminous ring, and a ribbon/knot/tassel accessory with a gold contract seal. Palette: blue-violet, cyan, gold and crimson.

The four SVG files are original manual redraws of the concept silhouettes, simplified for inventory readability. Production textures are rendered from SVG at 32×32; item-preview.png includes nearest-neighbour 32×32 enlargement and a 16×16 readability check. Generated raster artwork is not used as a game texture.
