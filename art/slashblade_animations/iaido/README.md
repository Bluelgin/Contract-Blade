# 黑狐居合动作样片

独立副本 `fox_black_iaido.bbmodel` 使用当前优化后的黑狐模型，保留全部原动画。
新动画：`animation.contract_blade.iaido_preview`。未改游戏资源、控制器、伤害或特效。

- 0～0.30 秒：侧身压低，右手握柄、左手扶鞘。
- 0.30～1.32 秒：静止蓄势，双手对齐刀鞘口。
- 1.32～1.40 秒：快速转身拔刀横斩（约两个游戏刻）。
- 1.40～1.82 秒：保持出刀姿势，留清楚的剪影。
- 1.82～2.80 秒：收势、回到扶鞘姿势，再复位。

`black-fox-iaido.gif` 为 Blockbench MCP 捕获的正常速度预览。
`setup.js` 添加临时刀/刀鞘参照，不修改模型几何，也不是最终游戏装备渲染。
重新打开工程后可执行 setup.js 恢复参照；实际骨骼动作已经在 bbmodel 内。
`iaido.blockbench-tracks.json` 保存 Blockbench 坐标的独立动作轨道，不能直接当成游戏导出格式。

后续接入时需将服务器技能阶段与动作时间对齐，处理刀鞘挂点及拔刀显示；本次只供观感确认。
