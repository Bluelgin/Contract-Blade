# 三狐 YSM 本地玩家测试版

这三个文件夹各自独立，使用 YSM 2.6.5 / Forge 1.20.1，不依赖契约之刃或车万女仆。原始女仆模型、资源包和 Boss 代码未被改写。

赤月使用当前粉白发色、无月轮、保留原袜子与尾巴的已适配模型。白狐、黑狐使用最新优化模型。只导出人形，剔除旧狐狸变身与隐藏月冠；低血量不会使玩家模型隐藏。黑狐仅为外观，不包含 Boss 技能。

保留原 Wine Fox / TartaricAcid、Blade Tetra 和用户角色包来源及原授权。双狐附原资源包 CREDITS.md 与 CC BY-NC-SA 4.0 全文。赤月附原始女仆元数据和来源说明；此文件不是新增授权，公开发布前仍须核对原角色包完整授权。

基础玩家状态与兼容动作取自 YSM 2.6.5 JAR 中公开的 default 模型，官方声明 CC0。作者：哥斯拉、端木一动不动、甜粽子、星屑海螺、蓝玫瑰、艾雷克亚。Retarget 按当前模型骨骼名称处理，缺失骨骼轨道移除；已有普通行走、奔跑、眨眼、尾巴和耳朵动作保留，另补玩家潜行、趴下、飞行、鞘翅等状态。第一人称手臂独立导出，同一张原生 512px 贴图。

本轮为可运行测试转换，不代表所有物品、骑乘、模组动作及极端姿势穿模已经通过实机视觉验证。YSM 模型包没有从加密文件中破解或反编译。

## 旋转飞行与三尾灵动（2026-10-10）

三个角色的普通 `fly` 复用 YSM 2.6.5 自动生成的可读内置 `wine_fox/01_taisho_maid` 大正酒狐原飞行动作，保留连续多圈尾巴旋转。该动作不是 default 模型的 CC0 资源，而是原酒狐包声明的 CC BY-NC-SA 4.0；完整原始署名及许可元数据附在 `TAISHO_FLIGHT_CREDITS.json`。不导入其狐狸变身、额外轮盘、声音或音乐。

黑白狐三条尾巴的飞行旋转补偿各自静态展开角，并错开 120 度。新增普通动作低优先级尾巴层：三尾错拍、逐节滞后、尾尖小波纹，以及经过限幅和平滑的转身/移动/升降响应。保留原骨骼、贴图、展开角；不增加每帧脚本监听，只使用动画表达式，每只三尾角色 9 条二阶平滑通道。

后续走跑重量感修订：低优先级尾巴层读取上一帧主动作 Root 的实际起伏，尾根到尾尖的响应频率由 3.6 递减至 2.0，减少跑步时的大幅左右摇摆，运动中侧尾渐渐收拢，停步和转向由二阶平滑保留余势。使用现有不可见 molang2 骨骼缓存走跑混合，每只三尾角色现在为 32 条平滑通道（替代上版的 9 条）；不增加骨骼、贴图、Java 事件监听。未经帧率基准测试，不宣称整体性能提升。普通飞行动作内容不变。

本轮只更新 YSM 测试包及测试目录，不改变女仆资源包或黑狐 Boss 资源。鞘翅、趴下等显式尾巴收拢姿势继续优先于普通摆动。
