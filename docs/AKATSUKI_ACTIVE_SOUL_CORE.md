# 赤月主动魂核：独立技能与可选追偿

本次规则取代旧文档中“只有已验证限伤才能生成魂核”的限制。

## 玩家体验

- Lv.2 解锁。主手合法觉醒赤月、剑灵驻留时，具有服务端原生攻击来源证明的命中尝试可以生成魂核。普通怪、训练假人、未适配 Boss 不再因没有追偿债务而失去技能。
- 已知保护阶段、初始化、失效载体及友方仍不提供攻击资格。未知减伤不等于生成了追偿债务。
- 生成间隔、每人数量限制、高空位置、空中精准点击及原生基础幻影剑触发沿用现有机制。
- 一次有效触发完成默认四段攻击；重复点击不重启，多个玩家共享目标冷却。

## 伤害分账

基础总伤害 = `(玩家攻击属性 × soulBurstAttackMultiplier + 目标最大生命 × soulBurstMaxHealthFraction) × 成长系数`。

成长系数 Lv.2 为 0.60，每级加 0.05，Lv.10 为 1.00。默认参数是攻击倍率 5、生命比例 0.005。总量按现有加权四段分配，不设额外固定 HP 上限，仅遵守 Minecraft 有限浮点表示范围。

已验证限伤仍可产生额外追偿，单独预留、结算和释放。基础伤害不伪造债务，不记成已偿金额；追偿失效后基础攻击可继续，但失去载体、目标身份或已知阶段变化仍终止整套技能。

## 攻击策略

默认 AGGRESSIVE 对独立攻击也开放精确来源/目标/同步调用范围内的事件取消与降额对抗，以及按真实扣血反馈切换通道。STANDARD 不启用该覆盖。作用域结束即撤销权限，不影响其他玩家或普通攻击。

没有新增未知生命字段反射写入、通用 setHealth 或实体删除式斩杀。UNRESTRICTED_EXPERIMENTAL 的旧生命补偿仍限于已有精确适配，并非所有未知 Boss 都能强制扣血。未知自定义受伤入口、生命系统及不可识别的保护阶段仍可能拒伤。

## 验证与诊断

新增纯策略测试覆盖普通/未知命中资格、伪造或过期载体拒绝、等级成长、四段守恒及跨玩家冷却。原生 Forge 夹具增加普通/未知目标自动生成、他人点击拒绝、一次点击完整四段实扣、重复点击及无虚构债务检查；原有追偿断言单独排除新增基础伤害，仍验证债务不重复偿付。

`damageDiagnostics=true` 可记录 SOUL_ANCHOR_CREATED、SOUL_ANCHOR_REJECTED、SOUL_BURST_STARTED、实际伤害和独立追偿结算。此开关会增加攻击日志，正式游玩建议关闭。客户端和真实 Boss 完整组合仍需人工验收，服务端夹具不替代真人演出与听感测试。
