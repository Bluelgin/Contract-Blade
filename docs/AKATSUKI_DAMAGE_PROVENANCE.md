# 赤月伤害溯源、十级追偿与空中拘魂

开发基线：PR #18 `02ffd9c61b676f61b531ecfe40a23c0b86a794cc`。本变更在独立分支提交，PR 目标为 `codex/akatsuki-domain`，不重写旧 PR 历史。第三方仓库与发行 JAR 均未修改。

## 玩家行为

领域仍按合法持刀、契约驻留及成长授权自动运行。正常空间斩保留保守基础伤害；只有原生攻击被**已验证特殊限伤**压低时，才出现可追偿债务。Lv2 起，该债务可生成头顶魂核。玩家通过拔刀剑空中机动接近魂核、明确瞄准并直接攻击一次，即启动完整短时轰击；范围斩、自动剑、投射物和其他玩家不能激活。

没有可信差额的普通怪物不凭空提供高额拘魂伤害。未知硬拒伤、合法护盾/正常减伤、初始化和受保护阶段均不作为“损失100点伤害”的证据。

## 数据流与边界

| 模块 | 职责 |
|---|---|
| NativeAttackOrigin | 原生 Player.attack 实际 hurt 操作、SlashBlade1.9.65 AttackHelper 的精确来源/目标单次调用证明；只开计算作用域不能授权伤害 |
| DamageProvenanceResolver | 复用 ContractCombatCredits 的真实载体、发射登记及 SlashBlade 弹幕作用域；不根据当前手持猜延迟弹幕 |
| DamageObservationService | 原生 hurt 的同步全调用 Scope；ForgeHooks 最终返回采样；实际护甲/抗魔函数输入输出；调用结束实际 HP；异常安全关闭 |
| DamageObservation | 不可变序列、玩家/目标 UUID、实体 ID、真实来源对象、服务器/维度、防御快照、E/A、阶段、可信度、有效期；未知 E 为 NaN |
| DomainTargetCompatibility / BossLimitAdapter | 单一可选适配注册表，已核实 cap 入口、纯读取的原生限额预测、阶段/生命接口 |
| SoulDamageDebtService / SoulDamageDebt | 唯一追偿账本；一条原生攻击一条有限差额；普通斩与魂核共用累计额度、预留、尝试与真实结算 |
| SoulDamageEngine | 已授权的有限伤害执行；五通道真实 HP 反馈继续复用；基础斩和追偿分别标记 |
| SoulDamageSafetyBudget | 玩家/目标共享滚动安全限额、同帧/频率/递归和爆发冷却；不是债务来源 |
| SoulAnchorService / Binding / Placement | 魂核生成、实际身份绑定、上方/侧上方碰撞检测、跟随、原生精准点击、短暂滞留 |
| SoulBurstService / SoulStageAllocation | 单次预留、有限阶段、水位再分配、阶段消费与结束清理；后续点击不追加额度 |

伤害采样不发探测攻击、不回滚生命。正常原生调用经过外层 Boss hurt、LivingAttackEvent、LivingHurtEvent、护甲/抗性/附魔/吸收、LivingDamageEvent，再结束。适配在具体原生 Math.min 限伤点采样；ForgeHooks 的 whole-method wrapper 读取所有监听器后的真实返回值。嵌套同目标调用独立采样，并从外层血差扣除嵌套贡献。`player_attack` 类型本身不能获得资格；延迟裸调用不能借用当前手持。原生证明绑定实际 Source 对象和目标，只能被最外层观测领取一次，finally 关闭。已登记弹幕继续使用发射时证明。未包围的子类最外层 hurt、未知防御覆盖、未知生命字段、事件取消/降额或 HP 流水线不匹配均拒绝生成债务。

这不宣称可以辨认所有 Mod 的任意 Mixin。已测试版本之外、未知盾/伤害转移和阶段生命系统必须继续提供精确证据，不能根据血差猜测。

## 累计追偿

设 E 为排除正常防御/吸收后的已验证理论 HP 伤害，A 为该次原生调用的实际 HP 损失。只有已验证特殊限伤时 L=max(0,E−A)，否则 L=0。普通斩最多消费 L×普通比例；完成魂核后，该次攻击的**累计**追偿最多为 L×魂核比例。

E=100、A=5、L=95 时：Lv2 普通斩11.4，魂核还能追加17.1，累计实际扣血33.5；Lv10 普通斩42.75，魂核还能追加52.25，累计100。原生已经扣100时，不再生成95或100的补偿。原始120、正常防御后100、限伤后5，则差额95，不是115。

| 等级 | 普通比例 | 完成魂核后的累计比例 | 新参数/原能力保留 |
|---|---:|---:|---|
| 1 | 10% | 未解锁 | 基础特殊限伤追偿 |
| 2 | 12% | 30% | 主动精准拘魂，兼容ID akatsuki_swords |
| 3 | 15% | 35% | 魂核默认寿命额外10 tick；原环斩 |
| 4 | 18% | 40% | 射线容差0.04→0.12；原锁敌 |
| 5 | 22% | 50% | 原五通道自适应按实际 HP 选择 |
| 6 | 26% | 60% | 成功斩魂4 tick下降减速；原反击 |
| 7 | 30% | 70% | 更高已验证债务额度；原连锁 |
| 8 | 35% | 80% | 原濒死救援、图腾及持久冷却不变 |
| 9 | 40% | 90% | 债务有效期120→200 tick；随机原生剑雨不变 |
| 10 | 45% | 100% | 已确认差额的完整体累计比例；仍受安全限额/阶段限制 |

所有比例在现有 `contract_ability_progression/akatsuki_domain.json`，Java fallback 与注册边界一致。旧数据包缺失新参数时使用对应等级 fallback，不创建私有经验，也不丢失十级解锁。

失败仍占安全尝试额度，不能靠失败退款反复打。债务分别记录 reserved、attempted、actual HP 和 paid；真正扣血才增加 paid。部分成功的普通斩可由随后魂核补到其更高累计上限；同一路径不能反复领取。到期、换刀、登出、维度/实体/阶段/防御变化终止旧资格；已开始的有限轰击可在最长32 tick内结束，但仍逐段验证。新的护盾或抗性不能被旧记录绕过。原生热键、丢弃/副手交换及涉及主手的背包操作会立即清除旧资格；seen 序列保留到原有效期，重放事件也不能重建。

账本按服务器、攻击序列及所有者/目标索引，有2048全服/64每玩家的记录边界。不写武器 NBT，不长期持久化。重启不会复活旧债，换刀也不会重置已经收取的共享安全额度。

## 预算与分段

默认 AGGRESSIVE；STANDARD 保守执行；UNRESTRICTED_EXPERIMENTAL 仍只能对有凭据的差额使用原有精确生命适配，不能任意反射改未知字段。

安全基线：单段128 HP、玩家每20 tick384 HP、目标共享每20 tick512 HP、200 tick窗口玩家2048/目标3072 HP、爆发总安全512 HP、目标爆发冷却60 tick。普通追偿另有目标共享12 tick频率，独立于视觉密度。

预留总额先受债务、玩家/目标共享安全、爆发总额及 `单段容量×段数` 共同约束，再按权重分配；达到某段上限时将余量分给有空间的段。384不会再被末段128截成358.4；512可分成4×128；请求1024在默认容量下最多预留/执行512。失败阶段不无限重试，未执行的 reservation 关闭释放占用但不重置已领取标记。

无可信债务的基础空间斩默认 `min(攻击属性×0.05,0.5 HP)`；它不能使用追偿的强事件权限或正常防御绕过。日志以 BASE_CUT / VERIFIED_RECOVERY 分账。

## 空中操作与显示

魂核为普通 Entity，注册ID保持 `maid_weapon:soul_anchor`，不保存、不可召唤、不参与 AI/掉落。默认90 tick，Lv3起100；绑定目标 UUID、实体ID、实例、所有者和驻留契约。

正常位置取碰撞箱顶部+2格，且至少比目标脚部高3.8格。巨型目标可用侧上方位置；每次位置必须通过已加载区块、世界高度、方块碰撞及目标身体交叠检查，空间不足时不生成/清理，而非塞进方块或降到地面扫刀范围。非标准巨型碰撞箱的可达性仍需人工模组组合验证。

原生 AttackEntityEvent 只接管直接点击。服务器独立验证：所有者、合法赤月驻留、同维度、存活/非创造旁观、最大8格的合法 reach、空中位置、准星射线、方块及前方实体遮挡、实体绑定、有效期、攻击冷却及同tick去重。DamageSource 自称玩家攻击不会通过。没有自定义“造成伤害”C2S包；其他客户端穿过不属于自己的核心瞄准原目标。

沿用赤黑碎片、脉冲与局部裂痕，低/标准/高档3/6/9碎片，64格距离裁剪、实例上限。未增加 Shader。Lv6短暂滞留只减缓下降，不清空掉落距离、不授予无敌。原生 SlashBlade 机动自身效果保持原样。

## 可选兼容与升级

实际伤害矩阵使用固定请求的显式验证来源作用域，验证的是真实服务端 HP 流水线，不是玩家手动伤害倍率。另有普通 Player.attack 与真实 SlashBlade AttackManager→AttackHelper 调用的独立来源证明测试；不能用固定请求夹具代替真人操作验收。

Boss适配只读研究 Cataclysm3.31、Legendary Monsters2.1.15、Goety2.5.58.4、Revelation2.3.4/内嵌RevelationFix4.6。可选Mixin必须检查版本、方法与原生限伤调用；不安装这些Mod也不能导致类加载失败。

Cataclysm 读取已核实 damageBucket 与距离减伤边界；合法距离减伤不作债务。LM仅验证具体生命API与HP一致的路径。Apostle普通外部、非WITCH抗魔分支单独核实；全头衔Apollyon/Nether生命机制不自动开放。真正测试成功/拒绝的组合见验收记录，不能由注册表名称推导“全部Boss已支持”。

旧 `akatsuki_swords` ID、熟练度存档、领域与剑雨协议保留；魂核从 LivingEntity 改为 Entity，`soul_burst` 握手版本为2，客户端/服务器必须同时更新。魂核原本不保存，旧存档无需迁移实体。旧伤害公式配置键与默认值保留并标明弃用；不再解释为追偿额度。已有配置中的60 tick魂核寿命保持作者设置；建议手动调整至90。开关 `bossAdapters && knownBossAdapters` 保持总开关/子开关关系。

MixinExtras0.4.1作为MIT许可运行库以Forge Jar-in-Jar打包；不把BladeTetra/Goety或Boss变成强制依赖。构建产物应使用无slim后缀的完整JAR。完整审计见 [审计报告](audit/AKATSUKI_PROVENANCE_AUDIT.md)。

实际通过、失败和用户停止后的未执行项见 [验收记录](AKATSUKI_PROVENANCE_VALIDATION.md)。
