# 赤月 · 断月蚀轨 — 五重幻影剑破核（PR #25）

## 玩家可以直接理解的规则

原生赤月攻击首先真实结算。符合安全核算的特殊限伤——**不要求 Boss 预先在适配名单中**——会留下有限且会过期的追偿额度。若普通怪没有特殊限伤，仅生成**单一普通暴击魂核**，继续一次精准命中后追加已验证原生掉血的 50% 暴击伤害。

对于特殊限伤，主核上方显示原先的**绯红残月、倾斜缺口星轨及三颗归伤星**。这三颗星**只是视觉，永远不是需要击中的目标**。玩家只需要反复瞄准同一颗中央赤月魂核：

- 使用**五支不同的原生 SlashBlade BASIC 幻影剑**命中中央主核。
- 每支幻影剑必须有合法的发射者、武器绑定和发射时战斗凭证；必须经过真正的服务端投射物扫掠/遮挡判定。同一个 UUID 最多尝试计数一次，原生幻影剑一旦碰撞就销毁，不会原地计数五遍。
- 连续两次有效计数至少间隔 **4 tick**。过快的幻影剑被消费而**不计数、不重试、不直接判失败**；不要求玩家手动按五次发射键，可用本体合法连射技能。
- 总窗口 **90 tick（4.5 秒）**，从生成魂核开始计算。每次命中不会刷新倒计时。超时本轮失败，并作废当前伤害凭证的高额空中追偿资格；不会影响该凭证尚可用的普通空间斩少量追偿。
- 前四次有效命中只有视觉裂痕和进度反馈，没有实际高额追偿；**第五次命中**后才由原有 `SoulBurstService` 分段执行灵魂空间斩。直接用刀近战点击主核不算五次之一，也不会立刻失败。
- 失败后必须再次通过**合法原生受限攻击**取得新的有效凭证，旧凭证不可重复套取奖励。成功或失败都由服务端裁定，客户端动画和暴击特效不提供伤害权限。

## 视觉保留与恢复

恢复最初的三归伤星、偏心轨道、残月图案和原有 3–5 段空间斩裂解演出。三副星不生成实体、不做服务端碰撞、不跟随镜头变化移动真实命中点。中央主核恢复以前宽容的幻影剑扫掠碰撞和注视纠偏，尤其适配本体默认的 Boss 自动锁敌。每次有效幻影剑碰撞使主月增加一道细裂痕（0–5）；星星一直保持可见直至最后的空间斩裂解演出。原有 Shader/粒子低画质开销保持最小。

## 不回滚的原有改动

- 原生伤害溯源、通用限伤识别、灾变 Cataclysm 3.31 的 `IABoss_monster` 适配，以及阶段保护。
- Lv.1–10 普通空间斩**已验证限伤追偿比例 2–12%**；魂核 Lv.2–10 最高追偿 30–100%；二者共用一份有有效期、不得超领的 `SoulDamageDebtService` 凭证。
- 未知模组敌对生物仍保留低频、受控强攻试探，不绕过所有自定义 Boss 的原生死亡/掉落/生命事件。
- 无验证数值、被硬拒绝、绕开 Forge/Vanilla 受伤管线的 Boss，仍不能凭空生成巨大追偿债务。
