# 赤月魂核视觉系统：断月蚀轨

## 通用伤害驱动的两条魂核路线（2026-10-17）

**核心玩法规则**：合法赤月原生攻击首先真实结算。只要能从**同一次**原生 `hurt` 调用、Forge 事件及最终扣血取得一致证据证明非原版普通防御限伤，就产生一份真实、有限、会过期的追偿凭证；该目标的魂核切换为「断月蚀轨」。如果没有特殊限伤证据，且原生生命损失被核实，就产生简单的普通暴击单核（Lv2 起实际扣血的 50%）。不使用 Boss 的注册 ID 作为是否允许破限的决定条件。

- `DamageObservationService` 首选已审核、版本限定的 Boss 原生限伤点；新增 `GenericSoulLimitEvidence` 对此前未适配的伤害压制（原始 `hurt` 入参、可信任原生攻击量和 Forge Hurt 事件之间的削减）提供**真实同步调用**证据。
- `NativeAttackOrigin` 的玩家或本体 `AttackHelper` 原生调度路径记录精准的 `DamageSource`、目标和被提交攻击的原始数值，绝不从战斗整 tick 总生命变化猜伤害。
- 只有后续仍遵守普通原版护甲、附魔、抗性、吸收和真实生命核算的目标才产生通用追偿；对不透明自定义血量系统、未能取得有效来源、早期直接拒绝、零扣血和异常额外扣血，系统继续保持不发行信用。故「通用」不是对任意不遵循 Minecraft API 的模组保证 100% 成功。
- `SoulDamageDebtService` 是唯一凭证账户；普通空间斩和精准魂核共享余额、层数、过期和阶段校验，普通攻击不能凭空反复发行债务。
- 普通空间斩的 Lv1–10 自动破限份额降为 **2%、3%、4%、5%、6%、7%、8%、9%、10%、12%**；魂核仍为 Lv2 30% 至 Lv10 100%，因此主要破限价值来自玩家主动击破魂核。**普通空间斩的原始攻击倍率（及 Lv10 无上限成长）不变。**
- 已有精确适配器的 Boss 保留可信阶段与初始化保护；**其他模组的合法敌对目标**允许通过精确 scoped damage 强攻，不仅因为目标有一个未验证的 `isInvulnerable` 标志就提前拒绝，但仍走 `hurt()`，不修改 Boss HP、NBT 或直接丢弃实体。原版生物、队友、玩家及非敌对目标不被这一未知强攻权限放行。
- Cataclysm 3.31：新增 `IABoss_monster` 分支（下界合金巨兽），原生 `Math.min(FF)` 限伤观察 Mixin 经版本与字节码校验。保留下界合金巨兽明确的攻击状态 4 转阶段保护、碰撞空间限制及原有原生死亡逻辑；头部原生代理攻击仍通过相同最终本体观察/结算，不能双算。

### 分层与职责

`NativeAttackOrigin`（原生调用来源） → `DamageObservationService`（事件观察 / 事实核对） + `GenericSoulLimitEvidence`（纯函数证据判别） → `SoulDamageDebtService`（短期信用与去重） → `SoulDamageEngine`（普通空间斩或追偿执行） → `SoulBurstService`（主动魂核阶段结算） → 客户端 `SoulEclipseVisuals` 与 `SoulEclipseGlyph`（纯表现）。

`SoulStrikePermissions` 只决定本次已授权的伤害执行是否可用强攻：已识别 Boss 的普通空间斩始终不得越权，已证明债务的攻击使用原有受控追偿，无适配器的模组敌对目标可使用 scoped 强攻以避免被单一自定义无敌标志阻塞。

### 回归关键用例

- 100 请求 → 5 实际伤害的已适配 Boss 仍形成 95 债务；十级自动空间斩上限份额为 11.4，主动魂核最高可追偿剩余份额，永不重复兑现。
- 未适配 Boss 但受到可信原生 `hurt` 截断、或 Forge `LivingHurtEvent` 有可信数值截断：认定特殊限伤、产生可验证债务；未知普通生物完整扣血仍只出现暴击魂核。
- 未知来源、保护阶段、事件拒绝、零生命损失、非原版自定义生命核算、无上界数值等继续不凭空发行。
- Cataclysm 下界合金巨兽新基类和原生限伤点应在装有 **确切 3.31** 模组的专服及客户端进一步实机确认；主线 CI 未必包含该可选依赖。
- 视觉仍为当前 PR 的**单核真实命中 + 三颗归伤星表现**，并非逐颗星体真实连锁命中；进一步强化玩法需另立可验证的客户端/服务端锁步状态机。

## 玩家面对的规则

- **普通暴击魂核**：仍是原有单主魂核，命中判定和收益完全不变。不会绘制星系。
- **验证过的特殊限伤**：同一主魂核展开「断月蚀轨」——一轮有斩痕的绯红残月、一条偏心且不闭合的蚀轨、三枚归伤星。主魂核**仍是唯一的可攻击点**，轨道和副星只是表现。
- **阶段变化 / 债务过期**：服务端根据有效追偿凭证刷新视觉模式，客户端收到同步后自动退回单核；未验证的普通防御损失绝不被装成破限。
- **魂核击破**：真实伤害仍由原有服务端 `SoulBurstService` 分段结算，客户端据既有每段同步报文依次演出：首星崩解 → 次星牵引 → 断轨归伤 → 终段主核月裂。部分服务端将段数配为 3 / 5 时，表现按固定三副星作兼容映射，不变更实际伤害段数和额度。
- 最终裂月使用细白红斩痕和散开的少量星屑，不使用无界大量粒子。

## 破限授权边界（普通空间斩修复）

- 普通空间斩即使在 `strategy=AGGRESSIVE` / Lv10 且攻击力属性极高时，也不再继承伤害事件反取消、改写削减额、Boss 专属无敌计时器跳过，或 `bypasses_invulnerability` 等特殊穿透标签。**实际伤害由目标自身的原生限伤决定**；这不是用固定 HP 上限给高数值整合包截断伤害。
- `RECOVERY_LOCKED` 期间继续执行的普通空间斩，同样不获得任何破限特权，不能偷走尚未兑现的追偿份额。
- **仅已有来源证明、且已预留相应债务的追偿攻击**继承原有强攻权限；普通暴击魂核保留已消费原生生命损失的防御去重及原生无敌帧处理，但不会取得特殊 Boss 无敌穿透权限。
- 注意：此前确定的**普通空间斩主动追偿等级比例仍保留**（Lv10 45%）；所以拥有巨额有效债务时，主动追偿本身仍可能造成大量伤害。若要进一步把“破限”完全锁定到断月蚀轨操作，需要另行改动成长规则，不能把无来源的普通斩击与有凭证的追偿混为一谈。
- 新增 `SoulStrikePermissions` 纯策略权限门、`SoulStrikePermissionsTest`，并在专用服务端夹具中对高属性普通切割、真正特殊限伤、已验证追偿、追偿冷却回退进行覆盖。

## 设计含义

| 可见部件 | 在玩法中的意义 |
| --- | --- |
| 斩痕主月 | 玩家必须瞄准的既有魂核 |
| 倾斜缺口轨道 | Boss 对理论伤害的特殊限制 |
| 三颗归伤星 | 未获兑现的伤害，纯视觉象征 |
| 依次熄灭 | 实际四段追偿事件 |
| 终结裂月 | 最后一段的确认反馈 |

配色：月核深绯色 `#A51131`、轨道银红 `#AE7883`、星点偏银白 `#FFF4E9`、终结红光 `#F3506C`。

## 代码职责

- `SoulAnchorEntity`：只增加一个服务端控制的同步布尔 `ECLIPSE`，不持有轨道粒子或客户端帧状态。
- `SoulAnchorService`：只从 **已验证的债务账本** 决定外观模式，已有命中判定、高度和生成冷却不变。复用每 tick 的服务器跟随更新，在需求改变时同步。
- `SoulBurstService`：只将此次已成功预留的追偿模式发给客户端；不改变伤害请求、预算、追偿率和分段顺序。
- `SoulBurstNetwork`：将报文协议升级到 3，给现有阶段 cue 加 `eclipse` 标志，防止最后一段时实体已销毁导致客户端误判；新旧客户端需要同版本。
- `SoulEclipseGeometry`：纯 Java、可测试、无 Minecraft 渲染 API 的固定轨道、3 副星坐标和分段索引。
- `SoulEclipseGlyph`：唯一管理 QUADS 生成与绯红/银白配色的轻量几何渲染器；不维护游戏状态。
- `SoulEclipseVisuals`：客户端 bounded 阶段队列，仅订阅渲染阶段并负责 5 tick 后过期、跨世界清理、64 帧上限和相机距离剔除。
- `SoulAnchorRenderer`：复用原实体基底和所有权瞄准标记；仅在星系模式调用 `SoulEclipseGlyph.idle`，收包后通知 `SoulEclipseVisuals`。

## 画质与性能

- Forge 原生 `POSITION_COLOR` 批次 / 无自定义 shader / 无外部材质 / 不依赖粒子贴图。
- 最低画质：16 段轨道线、三颗星点、极简终结（减少星屑）；高画质上限 40 段椭圆轮廓。
- 远于 48 格不渲染短期碎裂残像，实体原有 64 格视距淘汰规则保持。
- 阶段残像最多排队 64 个，生命周期约 5 tick；不在每帧创建实体，不改变服务端 128 活动爆发上限。
- 始终让单一主核实体负责拾取/点击、所有权、遮挡判断与服务端真实扣血；副星永远不会重复伤害或被范围拔刀斩误触发。

## 回归检查

1. 普通怪合法原生命中 → 单核 → 精准触发原版式 +50% 暴击，无星轨。
2. 已验证 Boss 特殊限伤 → 断月蚀轨 → 三星依序 + 主核终斩，不额外增加任何伤害。
3. 无追偿/已过期/转阶段/换刀/跨维度 → 不能继续显示旧星系或旧结算。
4. 最低画质、远距战斗、大量实体、退出世界后进入新世界，以及 3–5 段服务器配置。
5. Forge 服务端回归、CI 和真机资源包/Shader 兼容需分别验证；CI 通过不代表已完成所有显卡实机检查。

架构参考：Forge 1.20.1 对客户端专有粒子提供与服务端公共同步信息的分层，以及 Forge 的同步实体数据机制；沿用工程现有 `SoulRenderTypes` 和 `RenderLevelStageEvent` 管线，不移植或复制其他 Mod 的实现。
