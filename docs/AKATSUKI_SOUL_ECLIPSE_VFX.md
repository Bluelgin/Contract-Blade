# 赤月 · 断月蚀轨 — 三星连锁与终斩

## 玩家规则

赤月合法原生攻击优先真实结算，再观察是否存在可验证的特殊限伤。不以 Boss 名单决定能否生成破限星系：精确已知 Boss 适配器和通用同步原生伤害证据都可以产生 `SoulDamageDebtService` 凭证。普通怪物没有特殊限伤时，仍使用**单个暴击魂核**，命中后追加基于已确认原生扣血的 50% 伤害。

有限伤凭证的敌人显示**断月蚀轨**：一个位于 Boss 头上的主月 + 三颗沿固定世界倾斜轨道移动的归伤星。现在这三颗星具有真实服务端的**独立虚拟命中区域**，不再仅是特效。

1. 玩家持有有权使用的赤月，发射**原生 SlashBlade BASIC 幻影剑**。
2. 在 **48 tick** 内击中第一颗亮起的星；随后 **18 tick** 内打中第二星，再 **18 tick** 内打中第三星。
3. 第三星碎裂后 **16 tick** 内，用幻影剑或满足原有空中精准判定的近战攻击击中**中央主月**。
4. 只有这四次命中全部通过服务端认证，`SoulBurstService` 才预留并发放高额灵魂空间斩追偿。自动空间斩的弱追偿仍是独立并行能力，不触发星轨的自动成功。
5. **打错顺序、重复命中已破碎星、提前打主月、超时，立即失败**。失败作废**同一原生伤害凭证的空中追偿资格**，不会给予退而求其次的高额伤害；该凭证尚未消费的普通弱追偿不受影响。必须以新的合法原生受限攻击取得新凭证才能重新尝试。

※ 上述时长在此版中是固定的首轮测试节奏，而不是根据帧率浮动；分段追偿的 `soulBurstStages` 3–5 配置不改变实际必需的**三颗星 + 一次主月终斩**。

## 伤害额度与安全边界

- 所有高额追偿只来源于**真实且确认的原生攻击理论伤害与实际扣血差额**，不会因为主动连锁而凭空额外乘法。单次结算仍由现有 3–5 阶段 `SoulBurstService` 负责。
- 自动空间斩的 Lv1–10 追偿比例 **2%、3%、4%、5%、6%、7%、8%、9%、10%、12%**；主动星轨追偿 Lv2–10 **30% 至 100%**。双方消耗同一份有限临时 `SoulDamageDebtService` 凭证，不能重复领取。
- 直接普通斩、霸体、护甲和普通暴击不会因为星轨变成高额追偿；原有未知模组敌对目标的低强度、低频率试探斩及已适配 Boss 的阶段保护保持不变。
- 未经过正常原生受伤或无法验证有效 HP 的第三方 Boss 不保证能产生精确追偿；绝不自行修改 Boss 生命 NBT、抹掉实体或覆盖原生死亡动画。

## 架构与实现

| 组件 | 职责 |
| --- | --- |
| `SoulAnchorEntity` | 仍仅一个现有的服务端魂核实体；同步星系模式、冻结的轨道朝向、已破碎星数；没有额外三枚实体 |
| `SoulEclipseGeometry` | 唯一轨道与星星世界坐标算法，客户端绘制和服务端命中共享 |
| `SoulEclipseChallenge` | 只管理 0→1→2→3→终斩、截止时间、失败和对应债务弃权；本身不计算 Boss 伤害 |
| `SoulAnchorProjectileGeometry` | 有限长度的幻影剑飞行轨迹与严格小命中区域、瞄准纠偏几何 |
| `SoulAnchorProjectileService` | 原生 BASIC 幻影剑的发射时所有权/武器绑定证明、扫掠、碰撞排序；若打错星也扣除该幻影剑 |
| `SoulAnchorService` | 玩家近战中央终斩验证、实体有效性、星轨启用/生命周期、专服测试的隔离入口 |
| `SoulDamageDebt` / `SoulDamageDebtService` | 统一的可用余额与已预留额度；失败原子作废此批凭证的空中追回资格 |
| `SoulBurstService` | 只在连锁完成后照既定额度发放 3–5 段伤害；失败前不提前预留高额额度 |
| `SoulEclipseGlyph` / `SoulAnchorRenderer` | 冻结世界方向的星轨和真实进度亮灭，中央月核未解锁时不显示终斩瞄准辅助 |
| `SoulEclipseVisuals` / `SoulBurstNetwork` | 终斩成功后的短时回收 / 月裂表现；不接受客户端自报伤害 |

**重要技术区别：** 三颗副星是世界空间的**服务端虚拟小命中区域**，通过原生幻影剑的实际运动轨迹与对应 `AABB` 核实命中；客户端视觉旋转不再随视角 billboard，服务器朝向在魂核初次诞生时固定，从而避免「视觉击中、实际打空」。只有主月使用原有魂核实体的普通近战拾取；范围斩击、其它投射物、无来源伤害事件不能替代 BASIC 幻影剑推进三星。

- Cataclysm 3.31 下界合金巨兽在实机的头部代理命中、受击分类、转阶段保护、星系视效、光影兼容仍需用户客户端单独复测。主线 CI 的成功不等于完整真实灾变环境验证。
