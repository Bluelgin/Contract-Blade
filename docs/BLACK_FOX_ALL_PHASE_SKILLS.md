# 旧领域技能加入全阶段

幻影剑轮、领域交叉剑气、剑雨、领域封缄刀痕加入普通战斗的同一技能池，满血即可抽选。基础冷却依次为 180、200、240、220 tick，沿用全局节奏系数：满血 0.8、半血 0.68、30% 血量以下 0.6。冷却从技能起手计算，是最早可再次抽选的时间，不是定时必放。

执行时保留各自预告和伤害时间，不恢复旧版中心悬浮站桩、转阶段演出、常驻剑阵叠加及单次振刀打断。领域封缄刀痕附带一对有预告的有限次元裂隙，替代旧阶段每 32 tick 追加的常驻裂隙；不在所有技能上叠加环境弹幕。

四角封缄阵只在半血以下开放，仍整场一次。阵法存续时维持拆阵专用轻量技能池，旧领域技能不会额外叠加。最终核心只在本体血量耗尽时触发。
