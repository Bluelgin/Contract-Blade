# 黑狐血条

2026-10-07 接入用户批准的第二版简约像素方向。概念图不直接缩小使用：
`art/black_fox/boss_presentation/black-fox-bar.svg` 按整数像素重绘，生成
214×96 透明图集（三行各 214×32）。底框宽 182，血量填充宽 176，
名称使用游戏字体。正常、污染、失衡分别使用独立行，不引入新 shader。

服务端仍由 `ServerBossEvent` 同步真实血量。额外通知只携带该条的 UUID、
振刀累计数、外观状态和显示/关闭标志；只发给挑战者，并仅在显示或状态
变化时发送。客户端只拦截匹配 UUID 的 `BossEventProgress`，不扫描实体，
不按名称、颜色或翻译识别 Boss，保留原版插值及排列规则。

五枚刀痕使用真实 `BlackFoxBalance` 累计值；五次后进入失衡，五枚呈碎裂
外观，失衡结束后复位。客户端状态不参与伤害、振刀判定或阶段推进。
退出、败退、销毁清除绑定，切换世界不沿用绑定；缺少绑定时回退原版条。
网络版本随额外通知升级到 3；后续二阶段技能将开发协议升级至 4。
服务端和客户端需要使用同一开发版。

自检覆盖实际游戏 GUI 绘制、透明贴图、满/半/空血和异常进度裁剪、
无关紫色 Boss 回退及真实振刀累计值。三种外观的实际渲染预览为
`art/black_fox/boss_presentation/runtime-bar-preview.png`。

稳定版仍排除黑狐战斗与本血条；独立的核心血条不在本次实现范围内。
