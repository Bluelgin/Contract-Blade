# 五次振刀破势与整体提速

正常战斗使用五次指定技能的成功防御触发破势。连击 B、次元连斩、居合和远程技能可计数，普通试探、交错普攻、侧斩、虚招及 Boss 振刀后的返斩不计数。所有成功防御仍保留防御、反馈及评分；单次防御不直接打断 Boss。每个技能轮次最多计一次，三轮 B 和次元连斩逐轮计数，飞行物保留出生时的技能与轮次，不会按命中时的新技能误计；计数至少间隔 8 tick。

前四次只挡伤并提供 8 tick 的短暂保护；第五次在战斗调度时清理技能、剑气和弹幕，进入 30 tick（1.5 秒）的失衡窗口，再从零计数。失衡期间不继续攒计数，受到伤害也不再提前缩短窗口。血条原有五枚标记显示进度。

正常技能冷却与招间等待统一乘以 0.8，半血以下为 0.68，最后三成血为 0.6。技能预告、攻击节拍和原生连击状态不压缩；三轮连击 B 仍只在半血以下抽选，不能因全局提速提前解锁。

最终核心仍在本体血量耗尽时触发，不参与五次振刀破势。失败传送及竞技场规则不变。游戏内中英文挑战说明已同步。
