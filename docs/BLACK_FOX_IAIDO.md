# 黑狐居合聚能

已确认的居合样片接入现有 DIMENSION_STRIKE，不另加攻击技能或修改伤害、瞬移、
方向锁定和振刀判定。动作和特效共同采样服务端技能起始刻，而非客户端收到包的时刻。

`BlackFoxIaidoTimeline` 将样片映射到原技能窗口：现身时已有扶鞘姿势，现身至
命中前两刻为蓄力，随后快速拔刀；命中后短暂定格，再收势。
原技能现身到命中只有 14 刻，所以游戏蓄势比独立 1 秒样片更短，不延长攻击判定。

`BlackFoxIaidoCharge` 是独立的客户端渲染类：跟随 LeftHandLocator（刀鞘口），
六个方向、每方向两段细能量痕加速向鞘口收拢；最后三刻外围变淡，中心小光点增强。
只复用次元裂缝贴图、能量遮罩和既有加法能量 shader；shader 不可用时保留发光贴图回退。
开始拔刀即不再绘制蓄力。技能被打断/切换时自然消失，无计时器或粒子实体需要清理。

居合期间刀鞘跟随扶鞘手，刀体出鞘后跟随握刀手；其他技能继续沿用腰侧刀鞘。
扶鞘挂点旋转已从 Blockbench 预览换算，居合退出后清除位置/挂点姿势，避免污染连击 B。
主体光点约 0.065～0.10 模型单位，局部加法叠亮，不添加全身光球或重复模型外壳。

资产从 `art/slashblade_animations/iaido/fox_black_iaido.bbmodel` 通过
`tools/build_black_fox_iaido.cjs` 导出；不覆盖女仆模型包，尾巴仍由独立控制器负责。
验证脚本：`tools/validate_black_fox_iaido.py`。
