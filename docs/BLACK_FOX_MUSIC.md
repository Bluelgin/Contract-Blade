# 黑狐战音乐

开发版使用 PeriTune 的《EpicBattle_J》，全阶段共用一个本地流式音乐实例。二阶段不重播开头；末击黑洞阶段降低到原增益的 55%，让攻击音效更清楚。玩家振刀成功短暂压低音乐，退出、死亡或击败后最多两秒淡出。断线及切换世界立即关闭。

作者没有提供独立的 intro 文件，官方循环本身已经包含开头旋律。通过波形匹配找到最早接入点，仅保存原曲前 0.24075 秒的独有前导，然后在同一个音频流中接入官方循环 OGG，不再额外打包完整 91 秒首轮。官方循环中的主题重复仍会保留。资源重载后的恢复直接使用循环段，不重新播放前导。

客户端配置 `blackFoxMusic.enabled`（默认开启）及 `blackFoxMusic.volume`（默认 0.65，范围 0–1）控制此功能，同时遵守游戏的音乐音量。战斗中重新开启时停止原版背景音乐，避免叠播。没有全局音乐替换或音频引擎混入。

职责拆分：服务器控制器只发送开始/结束；客户端 `BlackFoxMusic` 管理战斗会话；`BlackFoxMusicEnvelope` 管理音量；`BlackFoxMusicSound` 管理声音实例；`BlackFoxMusicStream` 负责首段与循环衔接。客户端按已知实体 ID 查询，不扫描世界，不产生音乐实体。

入场采用 60 tick（约三秒）的平滑渐入，从静音逐渐达到配置音量；重新开启音乐也会渐入，不影响振刀压音或退出淡出。

`tools/build_black_fox_music.py` 生成前导与循环的 48 kHz 双声道 Vorbis quality 3 运行资源，并检查编码后衔接波形、记录校验值；原始下载不修改。两段音乐合计 1,225,486 字节，较上一版 2,537,676 字节减少约 52%，较最初 4,312,816 字节减少约 72%。来源与授权详见 `src/main/resources/licenses/black_fox_music/CREDITS.md`。双狐模型许可独立，不能因为音乐可商用就认定模型也可商用。

客户端资源自检覆盖真实 OGG 解码、首段边界与官方循环边界、流式声音注册、振刀压低、静音恢复、末击降低和离场淡出。听感和实战音量仍需玩家试听确认。

黑狐仍属开发内容，稳定版资源筛选不会包含这首音乐或未完成的战斗。
