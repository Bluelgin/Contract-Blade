# 黑狐一阶段技能与自然反制（开发版）

常规中距离选择使用十个等概率槽位：七个为次元突袭、裂隙交叉斩、弧形剑阵，三个为试探斩、双斩、半套连击 B。高度、拥挤距离、压力与次元突袭冷却仍优先处理，实际整场占比不是固定 70%。同一新技能不会连续选择；次元突袭冷却从 300 tick 缩短至 180 tick。

- 裂隙交叉斩：两个不同位置的裂缝展开，16 tick 锁定玩家当时位置；24/40 tick 发射原生紫色幻影刃。8–23 tick 蓄力与44–63 tick 收招可被普通命中打断，斩波也能沿用振刀反制。
- 弧形剑袭：有预警的侧向瞬移，18/50 tick 展开两波五剑弧阵，沿用凝剑、锁定和分批发射。第一波完全释放后再展开第二波。10–17、48–49 tick 和78–93 tick 为可打断破绽。
- 次元突袭大斩：命中后4 tick 起至技能结束前保留普通攻击反制窗口，潜入次元期间的免疫规则不变。

自然反制不要求某一套连击或命中特殊小目标：在上述窗口对黑狐造成一次实际伤害即可（普通近战、原生幻影剑等沿用既有第一阶段伤害权限）。反制清掉对应技能待发攻击，进入42 tick 破势，提供既有24 tick 玩家保护、格挡反馈与评分奖励；破势期间继续攻击不会无限重置窗口。连击 B 的专用对抗规则和二阶段伤害限制不变。

架构：每招一个执行器；纯 `BlackFoxOpenings` 管理窗口，`BlackFoxPhaseOne` 分发技能与反馈，`BlackFoxDomainAttacks` 保持60个弹幕总预算及清理。裂缝复用贴图和 shader，按服务端同步时间采样，不新增美术纹理或Boss主控制器内的大型技能分支。

验证：`tools/validate_black_fox_new_skills.py`；隔离原生服务端 `tmp/black-fox-new-skills-validation.log`。客户端观感仍需实机确认。公开1.1.1包不变。
