# 四角封缄阵

本体血量降至 50% 以下（低血量强化段）后，在下一次正常招间释放一次，暂无循环冷却。起手 12 tick 预告，展开四印，24 tick 后继续正常调度。四印位于场地中心 ±17 格、地面可近战攻击的高度，每颗 24 HP；可任意顺序击破。

复用目标核心实体的独立封缄变体，以原版末影龙 `renderCrystalBeams` 渲染各核心到本体的连线。不生成末影水晶，不爆炸，不破坏方块，光束不造成接触伤害。核心破坏即移除实体与对应光束，血条显示剩余数。

有印存活时，本体统一拦截伤害并限频播放振刀接触反馈，不消费玩家振刀输入、不奖励评分、不积累破势。拆阵期间暂停 B 连击、次元连斩和主动贴身追击；近身避让及普通技能仍保留。核心每 40 tick 交替发射一枚幻影剑，提前 8 tick 固定目标并提示；绝不四角同时持续弹幕。

四印全破解除保护，不另赠失衡。指定技能振刀仍可积累五次破势，但破势不解除阵法。最终核心、胜负退出、断线及领域清理均删除四印和阵法弹幕。部分生成失败时清理已生成核心并放弃该次阵法，避免无解保护；核心意外移除不重生。

客户端与服务端反馈协议更新为 6，联机需使用同一版本。
