# 次元突袭：动态空间裂口

用独立的 24 帧透明图集替代次元突袭的静态裂隙光圈；旧贴图仍供其他技能使用，不修改三轮 B 换位或幻影剑生成特效。

- 潜入：地面裂痕撑开、合拢，本体沿既有时钟淡出。
- 预告：现身点先出现狭长紫白裂纹，包含细分支与方位音效。
- 现身：裂口露出黑色内部，紫色边缘和细白流光沿不规则边界移动。
- 消散：裂口快速闭合，碎片短暂散开，不循环播放或堆叠残留。

裂口沿现身/斩击方向摆放，而非始终面向镜头；身体出现后裂口在其后方，不遮挡面部。无效现身点仍使用真实世界坐标绘制，避免跳过攻击时标记错误地移到本体位置。每轮重复同一服务端时钟。斩击仅由原有同步快照渲染，不再同时绘制第二份斩弧。

运行资源为 `black_fox_space_tear.png`，768×1280，6×4 帧，约 185 KiB。用固定图集 UV 采样，邻帧插值，不依赖资源包全局动画时间；半像素内缩防止串帧。无需逐帧创建纹理、读取文件、创建实体或屏幕后处理，未改动伤害、振刀和核心机制。

编辑源：`art/black_fox/dimension_strike/build-space-tear.cjs`，沿用项目 SVG → PNG 工作流；生成脚本验证画布尺寸、透明背景和独立动画帧。`space-tear-preview.png` 为六个阶段的静态检查图。构建不等于游戏内效果验收，仍需更新测试端后确认实机表现。
