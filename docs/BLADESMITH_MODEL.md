# 刀匠酒狐模型

当前暂停游戏内接入：不会自动安装，也不随模组打包。以下记录保留供后续修复。
原模型、动作适配和归档包均保留在 `art/bladesmith`。

模型包名称：行旅刀匠 · 酒狐。模型名称：刀匠酒狐。
模型标识：`contract_bladesmith:travelling_bladesmith`。

安装车万女仆 1.5.3 或更新的兼容版本后，本模组会在启动时准备独立模型包。
在女仆的模型选择界面选择上述模型即可；不会替换现有黑狐、白狐或赤月。
同标识的用户自装模型包优先，不覆盖用户编辑的文件。

## 游戏内检查

1. 打开一位女仆的模型选择界面，选择「行旅刀匠 · 酒狐」中的「刀匠酒狐」。
2. 观察待机、走路与跑步时的头发、狐尾、围裙和腰间装备。
3. 让她坐椅子、睡觉、使用钢琴或电脑，检查身体与尾巴位置。
4. 给她装备拔刀剑，观察手部、刀与刀鞘挂点；切换工作、受击后检查模型仍然可见。
5. 保存退出并重新进入，检查模型选择保留。

保留模型原有喝酒动作资源，暂未添加自主喝酒触发。
这里接入的是外观及原生女仆动作，不包含神域救援、剧情 NPC 或 Boss。
