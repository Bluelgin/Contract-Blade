没有新备份管理器或新永久事故状态机。保留的 `WorldPresent` 是一项正常实体生命周期事实：成功生成后为真，成功收回或实际删除后为假；卸载和换维度不能将其改成假。它保存在现有 SavedData 的普通目标记录中，没有装备副本、来源签名、消费历史或计时事故阶段。

## 正常存取与复制

正常收回只从当前真实女仆读取最新完整数据，不使用备份。主人、女仆 UUID、绑定和必要的狐灵身份必须匹配。编码失败保留活实体和原武器；濒死失败仍取消死亡以保护唯一实体。

显现从当前武器加载完整数据。在所有维度检查原 UUID，并检查成功生成后留下的世界存在事实。`ServerLevel.addEntity` 成功返回后才写入存在事实；第三方取消生成不能留下一个不存在的“活动女仆”。实体成功生成后才删除武器快照。

创造复制、正常物品移动及临时 `ItemStack.copy()` 不再是拒绝理由。一个副本可正常读出最新契约，但原女仆已显现或已卸载时不能再生成同 UUID 实体。普通魂符不需要证明来源或消费回执；旧契约本体会清空/标记失效，当前迁居位置仍使已离开武器的身份不能被旧武器越权操作。

服务端全局熟练度仍由 SavedData 和服务端成长入口写入。创造物品包里伪造的旧 Level / 计数会在成长档案中标记为不可导入，契约实体仍可使用。兼容清除旧根级不可信字段时，先保留这一成长防伪信息。

## 异常消失与原生备份

1. 保存成功的武器快照优先于旧事故状态。
2. 真实 KILLED / DISCARDED 事件能读取最后实体数据时，优先保存在当前武器；保存失败时保留一个最后实体快照，供修复后协调重试。
3. 区块卸载、换维度、登出及仅仅找不到实体都不是死亡证据。保留身份及最后位置，可走已有有界区块召回途径重试。
4. 找不到实体不再无限占用随行名额。清理运行时部署不等于删除契约身份，也不等于允许另造同 UUID 实体。
5. 当前快照已不可用时，由玩家明确请求 TLM 原生恢复。契约之刃不自动执行旧备份回滚。

在主世界，由有权限的操作者使用 `/tlm backup get <玩家>` 浏览备份；后续点击女仆/文件，由 TLM 的 BackupCommand → MaidBackupsManager → ItemCamera 生成照片，使用 ItemPhoto 恢复。TLM 的文件列举/读取以执行玩家当前维度的数据目录为基准，因此建议在主世界执行。

照片使用历史完整实体数据；胶片原生代码仅读取 AdditionalSaveData，所以紧急胶片适配保留原 UUID、ForgeData 与 ForgeCaps。照片生成可能使用一只临时实体；它不能清除真实活女仆的存在事实。ToMaid 本身不支持取消，真实 UUID 冲突通过短暂的待生成实体引用拒绝这次 EntityJoin，不写永久 NBT 封锁。

历史备份可能缺少最近装备、好感及其他进度。提示明确说明这一点；不能保证恢复全部最近变化。TLM 本体仍可能消费被拒绝生成的照片/胶片，应从其原生备份入口重新取得照片；本次没有重写本体消费行为。

## 真实武器损毁

入口仍是 ContractDurabilityMixin / 可选 SlashBlade 消耗适配 → ContractDurabilityBridge；只有实际耐久处理中的最终物品消费才安排救援。不订阅泛化的物品删除/移动事件，SlashBlade 仅 Broken 但物品仍在不会补偿。

- 原女仆已显现：保留她，解除失效绑定与投影。未加载的原女仆在下次加入世界时解除旧绑定，不能从复制快照另外造一只。
- 女仆在有效最终快照中：沿正常生命周期显现原 UUID，然后转为自由女仆。
- 原生生成被取消/无法生成：从最终快照制作一份 TLM 紧急胶片，保留装备、关系及 Forge 数据；不附加普通物品来源证明或第二份服务端完整载荷。
- 没有有效快照：不造默认女仆，清运行时名额、保留身份并提示原生备份。
- 多通道载体：分别投影现有活动/休眠契约快照到同一个耐久救援入口，普通客居通道不会继承狐灵专属身份。
- 内景损毁：停止该居住会话并返回玩家，交给同一耐久救援路径；不再为制造胶片删除活居民。

队列保留每人/全服预算、40 tick 确认窗口、失败退避和旧 SavedData 读取。旧未证明损毁、已预占交付或缺失身份的任务只保留原快照供管理员诊断，不自动重新补偿。它们不会封锁正常契约。新的成功补偿按事件去重并移出队列；不承诺断电时精确一次物品交付。

## 黑白狐、内景与能力

正常迁居仍使用魂符与缔结台；紧急胶片不是日常迁居材料。稳定绑定继续关联内景土地；既有好感、共鸣、模型、装备及通道数据保留。

FoxSpiritLedger 的主人、剧情来源、SpiritUUID 与 Token 仍验证特殊能力，不从外观授予剧情奖励。已释放、由账本确认属于主人的自由狐灵可通过既有武器右键缔约流程重新安置；转换失败回滚目标物品，成功后更新原账本位置，不发第二把奖励刀或创建默认狐灵。

IntrinsicSpiritApi 保留多契约通道。黑狐所有成长路线与白狐所有等级数值不改；真实剑灵显现时能力暂停，驻留时按当前完整快照恢复。仅删除历史事故/物品副本数量造成的误锁。可选 BladeTetra 等接口与依赖声明保持。

## 玩家界面

收起 Tooltip 只展示名字、共鸣和自然语言状态；Shift 显示主人、好感、熟练度成长目标与使用方式。删除旧 Part 档案、重复状态、计算式伤害堆叠和内部工作提供者名。配置成长目标不再展示原始实体注册 ID / TIER 代码。

魂符说明只讲缔结台迁居，紧急胶片说明只讲祭坛救援。中英文同步补齐。较大物品数据的玩家反馈给出整理背包/避免便携容器建议；原始 NBT 路径与物品贡献保留在日志。详细底层状态仅在权限 2 的 `/maidweapon recovery status <玩家>` 查询。
