# 万华御札 - 东方弹幕协奏 A (PR #27)

普通契约女仆专属的持剑协奏机制：契约女仆必须在 TLM 原生饰品栏真正装备万华御札；
觉醒剑灵及三狐/赤月路线仍无权启用本系统。客户端只能提交施法编号或一次空挥请求，
绝不提交目标、伤害、共鸣费用、女仆 ID 或攻击权限。

## 自动协奏：每次有效普通平 A 必定发弹

- 服务端 AttackEntityEvent 注册攻击目标；成功造成伤害的受支持近战/SlashBlade 攻击有后备入口。
- 客户端的 LeftClickEmpty 只发送不含数值的空挥请求，服务器验证实际普通契约资格后向前射出弹幕。
- 同一服务端 tick 同一名玩家只可触发一次，防止同一次剑击对多个怪物重复产生齐射；不是传统技能冷却。
- 命中目标时在约 2 tick 后开始协奏，每颗弹幕错峰间隔 2 tick 发射，保证同一目标有实际伤害机会。
- Lv.1 三枚，Lv.2 四枚，Lv.8 起连续三次合法命中可强化为六枚。自动协奏不消耗共鸣。
- 玩家更换武器、契约失效、下线、死亡或更换维度后，待发队列重新授权并取消无效发射。

## 主动符式：不再依赖技能冷却

| 符式 | 共鸣费用（按池上限计算） | 弹幕量与用途 |
| --- | ---: | --- |
| 灵针 | 8% | 两波，每波六枚，共十二枚；单目标追猎 |
| 散华 | 14% | 两波，每波九至十五枚，前段散开后段收束，最多三目标 |
| 护身 | 22% | 持续三秒、五至八次敌方投射物拦截，结束后追击 |
| 幻想万华 | 45% | 四波，每波八枚，共三十二枚，围绕目标错位展开再收束 |

实际费用通过 `ResonanceService.pay` 从玩家合法契约女仆的服务端共鸣池扣取，
例如上限1000时分别花费80/140/220/450。旧版非零主动技能冷却全部移除。
既有正式的共鸣免付费饰品仍遵守统一 `WAIVED` 规则，但一样受安全发弹限额约束。
同一服务端 tick 只接纳一次主动施法，以避免重传造成的重复扣费，这不是技能冷却。
支付发生在成功的权限、解锁、队列容量预检查之后，每次施法最多一次支付。

## 真实碰撞逐弹伤害与 2 tick 窗口

`DanmakuHitBudget` 为每波设置**单颗命中的伤害额度**、对同一目标可兑现的最大枚数，
以及散华的最多三目标上限。每颗弹幕都要发生原生 TLM EntityDanmaku 实际碰撞，
没有假命中、直接改血、穿透属性或跳过护甲。
`DanmakuHitPolicy` 仅在万华御札合法弹幕的 hurt() 调用期间，临时放宽 vanilla 普通受伤无敌帧，
目标至少相隔 2 game ticks 才允许下一次弹幕结算；然后恢复原本的普通无敌帧状态。
Boss 的自定义无敌条件、限伤、阶段及原生伤害事件仍然能拒绝伤害。
同 tick 抵达的多颗弹幕不会全部造成伤害，这是所选的安全约束。

整体输出仍受单枚伤害额、最大弹数、同目标间隔限制；
本版为避免低攻击力武器的弹幕在护甲下完全无感，单枚保底 1 点**原生伤害输入值**（非最终生命损失）。
高攻击力时按原定比例分配，绝不直接绕过 Boss 限伤。

## 长期性能边界

- 每玩家最多96枚附近活跃弹幕、128枚待发弹幕、全服最多1536枚待发弹幕；
- 每次主动施法最多32枚，排队错峰2tick，并对队列中的每次发射再次验证真实契约。
- 最多每玩家6个待执行主动多波符式；每 tick 最多发出8枚到期弹幕。
- 原生视觉/碰撞继续复用车万女仆，而不是另外写自定义渲染引擎或 Shader。
- **无传统冷却不等于无性能限额**。当弹幕数超过上限时拒绝新施法，不提前扣费。
- 主动施法取消原版按键体验不变：短按施法，长按约0.3秒打开轮盘，松开选中不直接施法。

## 验证与限制

JUnit 验证两 tick、逐弹6次/32发上限、三目标限额、共鸣费用换算和性能饱和情况；
CI 编译、Forge 相关静态验证与专服回归；客户端还必须检验 SlashBlade 真实攻击路径、
TLM 原生弹幕实际伤害、Boss 特殊帧、多人TPS与共鸣 HUD。
