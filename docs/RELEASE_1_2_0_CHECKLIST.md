## 本轮规则收尾

- 共鸣剑穗、同心结、无尽契约只投影装备，不自动切换战斗、喂食工作或作息。
  老版本接管时保存的任务/作息会恢复一次并清理快照，之后尊重玩家手动选择。
  `AutomaticWork` 两个旧配置键保留读取兼容，但不再生效。
- 灵结晶补上原生六台座祭坛配方：紫水晶碎片 ×2、青金石、荧石粉、红石、石英，消耗 0.2P。
  默认补充 250 共鸣；满值不会浪费消耗。启灵脉的生存材料链不再中断。
- 三阶灵脉依次使用，永久提升玩家的恢复倍率，不提高共鸣上限、不直接补满。
  升阶配方需要前阶物品；已用掉前阶消耗品时需另外制作一份用于合成。
- 无尽契约是终局的共鸣消耗豁免，不豁免拔刀剑魂力、原技能冷却或解锁条件。
  不会附赠万华符的弹幕功能；万华符消耗剑穗也不代表继承装备投影。
- 成长与灵脉进度属于玩家；共鸣池按女仆独立保存。升级保留整个世界目录及配置，
  单独跨服务器搬运武器不携带世界级成长数据。
- 1.2.0 发布构建不再沿用 1.1.1 的 Boss/领域裁剪。美术、配方、模型、许可与 Mixin 引用纳入产物检查。

## Tooltip 展示规则

用户已确认普通物品使用两页互斥展示：默认显示风味句和 Shift 提示，按住 Shift 后替换为
用途、操作与必要限制，不重复风味句，不添加分组标题。宠物及普通契约伙伴的状态常驻显示。
客户端统一处理按键和展示，物品逻辑不读取客户端按键；中英文说明同时维护。

赤月、黑狐、白狐同步使用互斥两页：默认为角色短句、契约身份与必要停用原因；
Shift 页为生效条件、实时数值及已解锁能力，契约与成长信息置于末尾。
不再重复长介绍、整条已领悟名单或黑狐剑技说明。狐灵封存物与原刀的迁居说明也归入 Shift 页；
迁出后的原刀仍保留必要提醒。下一项领悟及所需等级由服务端当前数据包里程碑投影，不在客户端硬编码。
本轮只改展示与只读同步信息，不改变技能、数值、授权或成长条件。
167 项 Java 测试通过，覆盖默认页、展开页、常驻状态、技能解锁、动态数值以及数据包自定义成长预告。
客户端实际排版仍需进入游戏查看。
