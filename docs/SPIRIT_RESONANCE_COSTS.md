# 四式共鸣经济与剑灵消耗 — PR #27

共鸣池服务端权威为 `ResonanceService`，默认上限1000，按绑定的契约女仆分池，并非全玩家共享单一数值。所有费用按当前池上限按基点（1%=100bp）向上取整且至少1；`RESONANCE_WAIVER` 饰品仍由基础服务判定，无需在能力里另设跳过逻辑。

黑狐剑核同时保留 SlashBlade 原有 SA 耀魂开销，且不会对剑阵的每颗幻影剑扣共鸣；
白狐誓约的**保命1HP与持久冷却**不受支付失败影响，只有额外净化、吸收和短时减伤需要支付；
赤月在共鸣不足时保留紧急续命和领域视觉，但本次二次领域攻势会被挡住。
星轨总共150点只在经过服务器认可的核心最终连锁完成并进入真实 burst 预订时扣取，五把剑命中不逐颗收费。
原生共鸣特权免付费仍应遵守全部既有短间隔、攻击权限和有效性校验。

## 获取方式：只保留当前已有的五种额外来源，外加自然恢复

1. 合法契约击杀：旧单位5点，默认池换算为25点。
2. 玩家与真实出战女仆对同一目标协奏：旧单位3点，默认+15点，每名女仆每20tick最多一次。
3. 玩家回血：每生命1点按旧单位1点，默认+5点。
4. 玩家饥饿值实际增长：每饥饿1点按旧单位1点，默认+5点。
5. 消耗灵魂水晶：旧单位50点，默认+250点，满额拒绝使用、临界值正确处理实际到账。

自然恢复默认存储+5/秒、实体闲置+10/秒、执行非战斗能力+5/秒、战斗/暴走+2.5/秒；可由灵脉全局1.00/1.25/1.60/2.00倍提升。**不添加振刀刷取、照料刷取或破限返还。** 被击奖励默认0；若存档已有非零配置仍按既有兼容配置工作。

## 验收

- 原生共鸣 `PAID/WAIVED/INSUFFICIENT/UNAUTHORIZED` 全部分支；
- 封界剑核重复触发/跟随切换防止两次支付，原生耀魂保持；
- 白狐主副手合法持刀支付、危机冷却、零共鸣保命；
- 赤月无共鸣的领域伤害门禁、空间斩按次支付、魂核星轨不按剑次数扣费；
- 灵魂水晶 200/1000 旧上限迁移、满值、剩余10点、消耗品与真实提示；
- 多人隔离、怪物限伤保护和局域网 TPS；
- Gradle build/JUnit、静态结构、TLM 专服夹具通过后仍须客户端实机验证。
