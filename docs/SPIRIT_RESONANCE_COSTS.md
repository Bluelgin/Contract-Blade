# 四式共鸣经济与剑灵消耗 — PR #27

共鸣池服务端权威为 `ResonanceService`，默认上限1000，按绑定的契约女仆分池，并非全玩家共享单一数值。所有费用按当前池上限按基点（1%=100bp）向上取整且至少1；`RESONANCE_WAIVER` 饰品仍由基础服务判定，无需在能力里另设跳过逻辑。

## 获取方式：只保留当前已有的五种额外来源，外加自然恢复

1. 合法契约击杀：旧单位5点，默认池换算为25点。
2. 玩家与真实出战女仆对同一目标协奏：旧单位3点，默认+15点，每名女仆每20tick最多一次。
3. 玩家回血：每生命1点按旧单位1点，默认+5点。
4. 玩家饥饿值实际增长：每饥饿1点按旧单位1点，默认+5点。
5. 消耗灵魂水晶：旧单位50点，默认+250点，满额拒绝使用、临界值正确处理实际到账。

自然恢复默认驻留脱战+2.5/秒（含非战斗能力待机）、驻留战斗/暴走不自然恢复；显现脱战+20/秒、显现战斗+10/秒。显现恢复替换驻留恢复，不叠加；均由灵脉全局1.00/1.25/1.60/2.00倍提升。**不添加振刀刷取、照料刷取或破限返还。** 被击奖励默认0；若存档已有非零配置仍按既有兼容配置工作。

## 显现恢复循环（本轮调整）

- 玩家主动召出女仆恢复她自己的共鸣，恢复多少后收回由玩家决定。手动显现无最低共鸣要求；零值和满值均不触发自动收回。
- 显现本身、战斗维持、普通受伤、手动收回及濒死保护收回不扣共鸣。保留濒死保护、原有冷却、召唤人数和距离/维度规则。保护收回只保存残血，不额外回到25%生命。
- 三狐现有服务端驻留权限继续生效：显现时暂停对应黑狐剑核/白狐祝福/赤月领域与魂核强化；女仆的正常行动、任务、战斗及普通契约万华御札规则不受此权限替代。
- 玩家造成或受到有效伤害、女仆战斗及剑灵攻势均报告短期战斗状态；驻留战斗不能靠漏报继续自然回能。显现后的恢复独立于活动优先级，旧能力报告只会选择战斗恢复，不会退回驻留速率。
- 黑狐按真实攻击窗口收费，无目标不收维持费；弹幕、连击、追击和反击共享同一女仆的20tick窗口。保留原生 SA 耀魂费用，模式切换仅免共鸣。费用不足停止新攻势，未付费窗口不能放行。
- 赤月所有目标及脉冲来源共享10tick空间斩付费窗口，最多每秒4点（默认池）；领域另外每秒2/4点，普通魂核20点、破限魂核合计60点。窗口按玩家+女仆+费用项目保存，不因换手或重建领域重复收费，注销/停服清理。原有攻击间隔、伤害、限伤和债务凭证不变。

### 配置迁移

恢复仍采用旧200点单位，再经 `ResonanceService.legacyScale()` 换算到服务器池上限。默认1000点池的倍率为5。
新恢复键 `storedRecoveryPerSecondV2=0.5`、`abilityIdleRecoveryPerSecondV2=0.5`、`combatRecoveryPerSecondV2=0.0`、`manifestedIdleRecoveryV2=4`、`manifestedCombatRecoveryPerSecond=2.0`，确保已有配置也获得本轮默认节奏。旧恢复键停止使用；`combatDrainInterval` 和 `maidEmergencyCost` 仅保留配置兼容，不再扣费。`recoveryDelay` 继续作为近期战斗状态超时。

### 回归覆盖

JUnit 覆盖显现/驻留与战斗状态矩阵、灵脉恢复时长、群体共享付费窗口、精确时间边界、支付失败、空闲与时钟回退。TLM原生夹具覆盖无免耗饰品的零共鸣主动显现、显现期间普通受伤不扣费、零值不强制收回、残血收回保留共鸣与1HP、保护冷却、切换手持物后的恢复、各女仆/玩家/复制品隔离和服务端窗口真实余额。
