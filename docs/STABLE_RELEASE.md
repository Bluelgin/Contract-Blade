# 稳定发布构建

使用 `-PstableRelease=true` 构建 1.1.1 修复版。此构建在 `build/stable-release` 独立编译，不影响开发测试端的构建文件。

`tools/prepare_stable_release.py` 从当前源码生成构建输入，保留契约修复、神社取刀与双狐模型。发布包不包含黑狐 Boss、挑战维度、仪式入口、战斗 SE、对应渲染、Mixin、对白和教程。开发源文件保持完整。

未安装 BladeTetra 时，白狐不提供尚未发布的梦境入口；已有相遇与神域回响保留。黑白狐模型包继续通过原生车万女仆模型体系加载。

旧版普通游戏存档可使用此修复版。已经进入开发版挑战维度的测试存档不应直接降级到此发布包，应先使用开发版离开挑战空间并备份存档。

发布前检查实际 JAR：版本、同心结配方、双狐模型包、缺失的实验实体与维度、Mixin 的类引用，以及契约相关验证。
