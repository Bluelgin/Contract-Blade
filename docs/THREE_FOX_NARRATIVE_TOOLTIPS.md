# 三狐妖刀 Tooltip：自然叙事与动态能力

## 玩家体验
- 普通悬停：先了解是谁、是否驻留，再读一段平实的角色能力介绍和两三项真实数值。人物背景由任务与场景讲述，Tooltip 不写口号。
- Shift：分别说明赤月的无归之庭、空间斩、刀势共鸣、特殊限伤魂核；黑狐剑核与解锁后的连击 B / 跟随 / 复数猎手；白狐守护、净化、疗愈、灵刃、双狐共鸣、濒危救援与狐之誓约。
- 语言：简体中文自然叙述；英文独立写作但信息等价；不出现「凭据、伤害预算、原生受击窗口」等代码迭代过程用语。
- 进度、数值、是否已解锁只取服务器同步的 ContractTooltipSnapshot，不再把默认等级强行推断为数据包自定义成长的实际等级。

## 架构边界
ContractTooltipComposer 负责识别武器、状态与共同的契约/成长/用法段落；AkatsukiTooltipSection、BlackFoxTooltipSection、WhiteFoxTooltipSection 仅负责各自的专属能力展示；ContractTooltipFormat 仅格式化动态数值。没有改变 NBT、契约权属、能力定义、伤害计算、数据包或服务器同步。

## 实机检查
1. 三把刀 Lv1/5/6/7/10、每级解锁前后、中文/英文、普通与 Shift 展开、未同步时等待提示。
2. 赤月剑灵显现、主副手切换、未授权；魂核未解锁时不可宣称已生效。
3. 黑狐 Lv5 连击B、Lv6 跟随、Lv7 复数猎手，以及自定义数据包里非默认等级的解锁。
4. 白狐净化/治疗、剑核搭配共鸣、Lv10 狐之誓约的冷却，未解锁时不显示。
5. 普通非妖刀契约武器、转移契约、不是原刀、无主或他人的武器。
