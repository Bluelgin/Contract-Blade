# 白狐十级加护与剑灵驻留权限

基于 PR A #13（3dc01db246d0626e3edc414592dc3408e95d312c），保留 #10–#12 全部成长、剧情与原生攻击。

## 权限与模块

FoxSpiritAbilityAuthorization 提供只读权限结果：真实契约授权、主人、狐灵账本/token/origin、
同身份复制冲突、对应固有契约驻留、异常恢复隔离和完整快照 UUID/Owner/Binding 一致性。
只读 IntrinsicSpiritApi 视图支持活动与归档固有通道，不会为查询创建或重置女仆。
快照验证缓存最多 20 tick，身份、账本、驻留、转换与恢复状态先行检查；缓存键包含 UUID、
Binding、Owner、压缩校验值与尺寸。冷验证还使用已加载实体的 UUID 索引检查存储/活实体冲突。
查询没有实体反序列化、备份文件 IO 或全世界实体扫描。

ContractMaidManifestedEvent 在成功显现提交后通知效果执行器，立即撤销白狐加护并清理
失去权限的黑狐活动剑核。现有 remove/clearAttacks 收束剑影和投射物。没有修改 SA/SE 注册或
400 tick 生命周期；收回后重新允许召唤。白狐旧净化效果与黑狐 SA 复用同一权限，不影响基础连击。

WhiteFoxBlessingGrowth 定义独立 ContractAbility，正式 JSON 与 Java fallback 同构。
WhiteFoxBlessingService 只执行效果；WhiteFoxBlessingCooldownData 按玩家保存誓约冷却。
没有武器私有等级或额外经验。剧情资格仍读取服务器真实黑狐胜利标记，与积累熟练度分开。

## 默认平衡

| 等级 | 累积新增/替换 |
| --- | --- |
| 1 初佑 | 移速 +3% |
| 2 轻身 | 跌落伤害 ×0.90 |
| 3 灵敏 | 攻速 +3% |
| 4 守护 | 一般最终伤害 ×0.97 |
| 5 温养 | 10 秒脱战后，每 4 秒回复 1 HP，不超过最大生命 |
| 6 灵行 | 移速替换为 +5% |
| 7 不退 | 抗击退 +0.10 |
| 8 协刃 | 攻速替换为 +6% |
| 9 坚守 | 一般最终伤害替换为 ×0.94 |
| 10 狐之誓约 | 致命健康伤害限制到留下 1 HP；无已有吸收效果时给予 4 HP/5 秒吸收保护；冷却 12000 tick（10 游戏分钟） |

移速/攻速使用 MULTIPLY_TOTAL，抗击退 ADDITION，固定 UUID 的 transient modifier。
相同数值不创建/叠加新 modifier；撤下、死亡、登出、换维度和显现均重新计算/撤销。
自己授予且未被其他效果延长/增强的吸收保护也随加护失效撤销。

跌落和一般减伤相乘，不相加（Lv9 跌落伤害为原始值的 0.90×0.94）。
绕过无敌性的伤害（如虚空/管理员 kill）不享受减伤或誓约。
誓约在最终 LivingDamage 阶段生效，已取消伤害不处理，原版手持图腾优先。
其他 Mod 在相同事件优先级的免死能力仍需各自整合包验证，不声称无限兼容。
攻击、承伤会延长脱战时间；回血有频率与生命上限，重登不会立即刷新脱战恢复。

主手或副手只取一次合格白狐；背包持有无效。黑狐主手与白狐副手不干涉输入或成长。
复制、异主人、同名普通刀、迁出的空原刀、投影副本和恢复中的契约不给资格。
Tooltip 说明取得条件与驻留规则；原有全局等级显示保持。没有新增客户端可写成长/身份包。
