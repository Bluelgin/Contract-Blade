# 赤月主动魂核：特殊限伤追偿 / 普通暴击（互斥）

## 战斗规则

- Lv.2 解锁；只有有效原生攻击与可验证的来源才能建立伤害额度。保护阶段、来源不可信、取消攻击或生命系统无法确认的目标不得无偿获得强制伤害。
- **已验证的特殊限伤**：魂核只兑现这次攻击尚未回收的伤害债务，与普通空间斩共享同一账本，并遵守等级的空中追偿效率。不会再额外施加攻击力 × 5 或按目标最大生命值追加基础伤害。
- **正常命中，无已验证特殊限伤**：玩家原生攻击已造成正常伤害；精准击中魂核才追加该次**实际生命损失**的暴击增量。采用既有成长参数 `resonance_hit_ratio`：Lv.2 解锁后固定为 50%，相当于原生命中的 1.5 倍，而不是将 1.5 倍重新打一遍。
- **来源不明/非线性减伤**：不会猜测理论损失、制造债务或者凭空发放暴击。后续有真实、可验证的普通原生命中时才可获得暴击额度。
- 两种模式互斥；每个原生命中凭证只允许一次消费；不允许旧式立即共鸣在玩家攻击时先额外打一次伤害。
- 普通暴击依据**原生攻击经过护甲/抗性后的真实扣血**计算；魂核分段不再二次扣除同一层常规护甲/抗性，但仍遵守合法攻击与目标阶段校验。
- 保留精准空中近战、原生幻影剑触发、高空位置及目标共享冷却。成功触发后按 3–5 段（默认四段）守恒分配伤害。
- 配置 `soulBurstAttackMultiplier`、`soulBurstMaxHealthFraction` 为遗留兼容项，不再影响在线技能伤害。

## 安全约束及回归

- 伤害证明与载体、目标实体、维度和阶段绑定；切换武器、目标失效或凭证过期就拒绝兑现。
- 已认证特殊限伤不会被普通暴击叠加；技能不回填债务，也不会被动重复攻击。
- 单元与 Forge 验证夹具需检查普通暴击、原生限伤追偿、未知来源不给免费技能、分段守恒、同目标互斥和一次性消费。
- 本次 PR 未执行的第三方模组端到端测试不得宣称通过。
