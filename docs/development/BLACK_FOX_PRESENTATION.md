# 黑狐视觉、声音与镜头

战斗时钟和伤害由服务端技能执行器决定；客户端只读取同步状态播放表现。
本页是当前表现的维护入口，逐次调整与资源制作过程位于[历史归档](../archive/black-fox)。

## 空间裂口与斩击

次元突袭使用独立图集表现潜入、现身预告、裂口与闭合，朝向取真实攻击方向。
采样以同步技能时钟为准，不用资源包全局动画计时，也不逐帧创建纹理或效果实体。
裂口位置须正确转换竞技场局部坐标与世界坐标，技能结束后不能堆积残留。

重斩分为明亮核心、紫色斩带、光晕和残迹，各层独立消散。
`BlackFoxSlashTimeline` 只负责视觉寿命；`BlackFoxEffectQuad` 复用既有批次，
不因表现另造伤害时间线。源资源位于 `art/black_fox/dimension_strike`。

## 血条与反馈

自定义血条按绑定的 Boss UUID 显示，保留真实生命进度和破势累计。
未匹配的 Boss 使用原版显示，不能按名称、颜色或翻译猜测身份。
血条状态及刀印连线不参与服务器阶段推进。

出招声、精准格挡和第五次破势使用不同强度反馈。
镜头反馈只作短促滚转，不改鼠标瞄准、服务器朝向或攻击判定；退出与换世界清理。
`combatFeedback.parryShakeStrength` 可调震动强度，设为 0 关闭；
`combatFeedback.bossImpactShake` 单独控制 Boss 重斩震动。

## 退役资源与验收

1.2.0 已移除背景音乐及其播放、压低原版音乐的逻辑，保留战斗音效。
旧音乐实现和素材许可留在历史资料中，不作为当前功能介绍。

动态图集、截图与时间线检查只能确认相应资源和渲染路径。
声音听感、镜头舒适度及第三方 Shader 兼容仍需实际客户端验证，
不能将旧稿中的一次通过记录泛化为所有环境通过。
