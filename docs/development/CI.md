# 持续集成

`Contract Blade Core CI` 在 PR 和主分支提交时运行：构建与行为测试、Mixin 重载回归、全部轻量数据及资源校验、共鸣与反噬（含重启）、投影、随行、万华四波以及 TACZ 原生回归。Gradle 缓存由 `setup-gradle` 统一管理。

需要完整兼容回归时，在 Actions 手动运行同一工作流并启用 `extended`，追加 BladeTetra 觉醒、魂核伤害、薪火双模组及其余专用服务端场景。

需要美术导出核对和实际客户端录像时启用 `visuals`。室内世界预览独立在 `Contract Interior Preview` 中手动运行。录像与预览不再由普通文案或兼容代码修改自动触发；它们是补充验证，跳过不代表通过。

## 已知录像限制

2026-10-30 的旧工作流 #41006649314 中，客户端录像的换维度、死亡和轮盘重新同步场景没有采集到预期画面；该记录保留为未通过，不能视为这些场景已完成自动验收。原生万华回归仍在默认 CI 中运行。修改相关客户端行为时，应手动重跑录像并结合实际游戏确认。

测试日志与构建产物仍上传到 Actions 附件。CI 通过不自动发布版本或创建 Release。
