# 万华御札：普通契约武器固定弹幕强化（PR #27）

## 定位及资格

万华御札是**武器强化饰品**，不是十级成长路线。只有普通契约女仆真正佩戴御札，并且**驻留在玩家当前主手的合法契约武器内**，才可以使用其弹幕能力；已显现女仆、三狐、赤月和内在剑灵一律不能借权。资格入口 `DanmakuEligibility.context` 验证完整契约权限、女仆驻留数据以及真实原生 TLM 饰品槽。

现有 `ContractMastery` 不会被修改、清空或迁移，但**万华御札不再依赖任何等级**。为降低本 PR 与现有测试夹具的耦合，部分 Java 方法暂留未使用的 mastery 参数，只作为接口兼容占位；所有返回值均与等级无关。

| 护身 | 3 秒最多拦截六次真实敌方弹体；结束后有界反击八枚，每弹面板 2.5% | 16% |

四式完整开放，轮盘不再显示等级门槛、锁标或灰化符卡。现有 2tick 同目标伤害窗口、真实车万弹幕碰撞、原版 Boss 保护、支付状态和特效全部沿用。

## 驻留生命周期

显现、解除绑定、移除饰品、切换主手、死亡、跨维度等导致资格失效时：立即拒绝新的自动协奏与施法；守护和未执行波次在服务器 tick 中止；队列每次发射会重新核对当前绑定；已经在空中的弹幕在真正碰撞时重新核验资格，因此不再造成伤害。已支付的共鸣不退款，避免切换状态反复刷取。客户端由服务器主动同步资格变化并关闭旧轮盘、清理表现状态。

## 技术边界

- 保留 `DanmakuCombatService` / `DanmakuEligibility` / `DanmakuWaveSessions` / `DanmakuShotQueue` / `DanmakuHitBudget` / `DanmakuGuardService` 分工，避免增加巨型类。
- 每玩家最多 96 个活跃、128 个排队弹幕；全服 1536 排队，每 tick 最多 8 个实际发射。四式保留原短间隔和服务端支付门控。
- 性能、攻击面板缩放、十级以外的其他系统、内景、三狐共鸣消耗一律不变。
- 新的 JUnit 与原生测试要验证所有旧等级下**相同的固定输出**；真实客户端需核验显现/归刀、旧空中弹无伤害、换手与多玩家隔离。旧版录像不能替代本轮实机证据。
