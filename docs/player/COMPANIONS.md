# 契约女仆：呼唤与日常

持有契约武器时，按呼唤键（默认 `]`，可改键）让女仆显现或收回。
切换手持物品不会自动收回主动呼唤的女仆。手动呼唤与收回不消耗共鸣，
共鸣耗尽也能正常手动呼唤。

## 留在家中

使用车万女仆本体的家模式或待命，让她留在指定位置。
居家和待命不占跟随名额，跟随人数默认一位，可通过[配置](CONTRACT_CONFIGURATION.md)调整。
居家女仆不会为了玩家受伤而被强行拉到身边。

远程收回要求同维度、32 格内，并通过原有的安全检查。
距离过远或区块未加载时，先回去找到她；系统不会为了收回而复制女仆或强制加载区块。

## 工作与装备

共鸣剑穗、同心结和无尽契约保留对应的装备投影。
它们不再自动切换工作和作息；战斗、喂食与日常任务在女仆界面自行选择。
女仆显现时的实际工作与能力仍受车万女仆及已安装兼容模组的规则约束。

物品默认显示简短介绍，按住 Shift 查看用途、操作和条件。
专属剑灵的说明也分为角色介绍与能力详情，具体解锁以当前服务器数据为准。

## 升级旧存档

更新前备份整个世界，并保留旧配置。女仆背包、身份和契约数据属于存档的一部分，
成长与共鸣不能靠单独搬运一把武器完整迁往另一服务器。
修复会防止相关问题再次发生，但无法凭空找回更新前已经丢失的物品。
