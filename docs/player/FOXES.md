# 神社、白狐与黑狐挑战

## 遇见白狐

安装拔刀剑后，在新生成的雪地平原寻找神狐神社。
随身携带的拔刀剑杀敌数合计达到 520，手持蛋糕右键供奉刀架；
供奉成功后空手再次右键，取走白狐原刀。
普通合成的白狐刀不会自动获得神社中这位白狐的刀灵。

取得白狐后，沿用契约女仆的[呼唤与收回](COMPANIONS.md)。
女仆版本的黑白狐外观由模组准备，不需要安装 YSM；玩家自身的 YSM 外观另行安装。
现行版本不要求等待次日对白，也不需要先完成 BladeTetra 的神域剧情。

## 挑战黑狐

不需要安装 BladeTetra，但需要拔刀剑。
携带属于自己的神社白狐原刀，白狐仍须驻留其中：

1. 制作拔刀剑的黑狐刀，在白狐供刀台后方的小神社找到预留凸起。
2. 在凸起上放置拔刀剑挂刀台，将尚未拥有契约或刀灵的黑狐刀放入。
3. 在凸起八格内放床，按原版入睡条件于夜间睡下，持续一秒后入梦。

这是神社的固定入口，任意黑石块与床不能替代。
入梦时原黑狐刀由场景暂存，挑战失败会送回并归还，不以死亡作为失败惩罚。
本体生命耗尽后仍需处理最终核心；确认胜利后，领域出现崩坏倒计时，结束自动返回。

胜利后回副神社，空手取回属于自己的原黑狐刀，获得黑狐刀灵及专属 SA。
不会再额外生成第二把奖励刀。若原刀架已拆或被其他刀占用，
在原位置补回空挂刀台并靠近，避免继续覆盖放入其他刀。

## 迁居与保存

白狐、黑狐沿用缔结台与空魂符的迁居流程；只能处理自己的有效契约，不能覆盖其他刀灵。
显现中的女仆需要先能安全收回。迁居保留女仆身份与装备，不会复制另一位伙伴。
白狐迁出原刀后，需迁回自己的神社原刀才能恢复入梦资格；请保留原刀。

背景剧情暂不主动展开，不需要寻找尚未接入的刀匠救援或污染源 Boss。
战斗难度可由服主通过[配置](CONTRACT_CONFIGURATION.md)调整；
能力成长见[万华御札及三位剑灵](ABILITIES.md)。
