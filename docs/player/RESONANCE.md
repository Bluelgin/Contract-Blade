# 共鸣、灵脉与无尽契约

共鸣是契约能力使用的资源，与女仆好感度分开。
每位契约女仆各自拥有共鸣池；同一玩家的契约成长等级共享，但不会共用同一池共鸣。
默认上限为 1000，升级时旧共鸣按比例转换。

## 恢复循环

默认自然恢复速度如下，未计灵脉倍率：

| 状态 | 脱战 | 战斗中 |
| --- | ---: | ---: |
| 驻留武器 | 2.5 点/秒 | 不自然恢复 |
| 女仆显现 | 20 点/秒 | 10 点/秒 |

让女仆显现可加快恢复；显现时暂停对应的专属剑灵强化。
手动呼唤、收回与普通受伤不扣共鸣。技能仍受资格、解锁、原生资源及冷却约束。

## 灵脉与灵结晶

初醒、流转、无尽灵脉依次使用，永久提高玩家的自然恢复倍率，最高两倍。
灵脉不会提高共鸣上限，也不会立即补满。后阶配方需要前阶物品；
已经使用前阶消耗品时，需要另外制作一份用于合成。

灵结晶可通过祭坛制作，默认补充 250 共鸣；满值时不会白白消耗。
实际配方与服主调整后的数值以游戏内显示为准。

## 无尽契约

佩戴后保留武器与护甲投影，并免除对应女仆的契约能力共鸣费用，驻留武器时也生效。
它不会免除拔刀剑耀魂、原生技能冷却或成长条件，也不附赠万华御札的弹幕。

服主设置见[契约配置](CONTRACT_CONFIGURATION.md)。
精确费用与结算边界见[共鸣技术说明](../development/SPIRIT_RESONANCE_COSTS.md)。
