真实 Minecraft 1.21.1 / NeoForge 21.1.219 / TLM 1.5.3 / Java 21 客户端和专用服务端。Linux X11 原始截图，无合成、重绘或裁剪。源自本轮实际运行；完整女仆快照没有进入客户端网络包。

## 观察范围

- `01–06`：本轮此前投影增量的原装备、剑穗、Shift 原文本、同心结、取下恢复和护甲模式。实测护甲 `8 → 20 → 8`，护甲模式保留真实铁剑；相应 attributes 文本在本目录。这些图不用于证明最终按键。
- `07–09`：最终代码恢复 `]` 召回与原粒子，绑定剑右键打开 TLM GUI；原守护缎带、护主结及并契之环实际装进 TLM 饰品栏。物品/任务选择操作均由真实客户端完成。
- `10–11`：第一次真实僵尸攻击触发 GUARD（同 UUID），测试敌人在观察后用命令清除，随后未按召回键，正常 400 tick 保护/战斗延时结束后自动归刃。第一次 4 秒后的玩家生命已被原版饱食恢复，不作为“护主治疗”的证明。
- `12–13`：玩家在 TLM GUI 手动选 Attack，经归刃、真实受伤、护主再显现后仍为 `touhou_little_maid:attack`。为隔离伤害观察，临时关闭本测试世界 `naturalRegeneration`，之后恢复；玩家实际生命 `20 → 19.4375`。第二次战斗截图，第三次单独重复的原版 `execute on attacker` 记录：僵尸 `20 → 13.224`，攻击者为原女仆 UUID `[I;1073329287,-2003284189,-1444728630,-519556051]`；第三次敌人自然被女仆击杀，未用命令伤害或清除。
- `14–15`：默认 O 实际激活、共鸣连续燃烧，期间 `]` 不召回；再次 O 结束归刃后余额保留为 375，不重置。只证明该输入和执行子集；完整完全显现演出、全部剑灵能力、多女仆和耗尽反噬客户端闭环未完成。
- `16`：真实 GUI 将本女仆载体放进她的背包，原保护逻辑退回主手；实际服务器清单只有玩家槽 0 一把契约剑，女仆背包没有副本，UUID 未变。菜单中按 `]` 不触发召回。

女仆是普通女仆选用现行 `contract_fox:fox_white` 模型；**不是白狐内置剑灵获得、觉醒或技能验收**。普通剑/台流程沿用先前核心增量的实际合成与缔结证据。本次护主结由命令准备后通过真实 TLM GUI 装配；原祭坛配方已接入，但未完成实际搭坛合成验收。相机位置/朝向、平台、测试敌人和初始装备使用本地 RCON 设置；没有修改技能执行器来制造图像或通过标记。
