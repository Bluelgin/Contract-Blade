# 赤月异闻 · 人物与意象档案

> 剧情创作中的角色基线，不作为现行游戏代码或配音的既成事实。

## 朝雾纱夜 / 朝霧 紗夜

- **旧时代身份**：带着一把陈旧打刀旅行的少女。
- **现世名称**：赤月（妖刀与刀灵的称呼）。
- **性格方向**：活泼、爱开玩笑、嘴硬、略有冒失；会害怕，也会为别人坚持。她对熟悉的人会耍赖、撒娇，碰到难题喜欢先装作自己能处理。
- **日常愿望**：带刀看海、尝遍城镇的点心，等这一趟结束好好休息。
- **弱点**：太容易把照顾别人排在自己之前；不愿承认伤口尚未愈合。
- **人物动机**：保护最后的避难者，同时不愿让多年的旧刀从自己生命中消失；在无法再以人身持刀时，主动选择融合。
- **不应写成**：天生冷漠的战斗机器、等待别人赎回的囚徒、靠失忆支撑所有情节的空壳。
- **真名表达**：“朝雾纱夜”不取代“赤月”；两个名字属于同一段生命的不同阶段。

### 台词语气

过去篇更轻快，常用简短问答和小小的插科打诨：例如“这不重要！”“不许笑！”“那就约好了！”。
现世篇仍会调侃玩家；谈到旧事时可有停顿，但避免突然变得充满高深哲理。

## 旧刀（未命名）

曾与纱夜多年相伴的旧打刀，刀鞘与缠线经多次修补。纱夜经常把它当成能够倾听的同伴；有时刀鞘会轻轻震动。

- **确定的情感事实**：纱夜珍爱它，不愿轻易更换，并希望与它一起回家。
- **暂不确定的世界观事实**：旧刀是否原本具有独立意识；融合之后旧刀与纱夜是两个意识、一个混合意识，还是仅余纱夜。
- **叙事原则**：不要仅为制造悲剧就让旧刀濒死，也不要马上把全部秘密讲透。
- **命名悬念**：纱夜曾答应一个孩子，等想出名字再告诉他；在过去篇里始终没有为刀取名。

## 教堂老妇人（未命名）

过去教堂的管理者，温和、务实，习惯担心总是受伤的纱夜。她管理远行登记册：姓名旁画圆圈表示归来。最后一批避难者安全抵达后，仍寻找纱夜三日；随后登楼敲响晚钟，并为后来者留下记录。

**对白风格**：像长辈一样平常地唠叨，不承担大段设定讲解。

## 最后一队避难者

共 **四十三人**，其中有孩子、老人、普通居民。一名小女孩曾对纱夜说“那我陪姐姐一起害怕”，另一个孩子曾询问旧刀的名字。两名孩子可在后续修订中合并，也可以保留为不同人物。

他们的生还不是抽象数字：这四十三个人使纱夜的选择具体、有重量。

## 现世玩家

- 在原有玩法中锻造模块化拔刀剑，刻入血晶等条件后，完成赤月觉醒。
- 与数百年前的纱夜没有预设转世、宿命恋人或旧时代血缘联系。
- 参与方式是**陪伴、观察、发现、回应**：发现旧教堂、找到登记册、敲响晚钟。
- 不把过往改写成“玩家拯救了纱夜”；他可以陪伴如今的赤月开始新旅程。

## 物件与意象

| 物件 | 表层样貌 | 两个时代之间的含义 |
| --- | --- | --- |
| 登记册 | 姓名、归来圆圈、最后一页的补记 | 已经发生的历史，迟迟未传达给当事人的结果 |
| 歪歪扭扭的小刀 | 纱夜在名字旁画的涂鸦 | 少女活泼的生活证据，使她从“妖刀传说”成为真实的人 |
| 旧钟 | 荒废教堂钟楼上生锈的铜钟 | 约定的履行、好消息的传达 |
| 褪色的红绳 | 旧钟绳拆下的小段，绑在刀鞘上 | 不要忘记归家的路；具体位置仍待统一校稿 |
| 断刀 | 战斗中折裂、经融合出现血色刀锋 | 纱夜主动选择的对象；不是现世玩家锻造的同一实体 |
| 血晶 | 现世玩家制作并刻入的觉醒媒介 | 与旧时代赤月传承发生联系，具体规则未定 |
| 教堂 | 原本温暖的避难所，后来焦黑破败 | 初见时像危险遗迹，了解真相后是归来的地方 |

## 剧情保留语句

- “那我陪姐姐一起害怕。”
- “如果以后我再也不能握住你……那就让我成为你吧。”
- “原来……他们都回来了呀。真好。”
- “朝雾纱夜。那是我以前的名字。”
- “我们一起回去吧。”

以上是现有草稿中的关键句，后续整体润色时可改，但应保护其情感作用。
