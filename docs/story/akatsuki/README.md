## 核心概念

- **朝雾纱夜（朝霧 紗夜）**曾是活泼、有些冒失、习惯对一把旧刀说话的少女。
- 她与旧刀相伴多年，有普通的愿望：看海、旅行、吃点心，和它一起回来。
- 战争中，她为掩护最后**四十三名**避难者，在月夜的山路上留下阻挡追兵；刀折、人伤，她选择与刀融合，最终失去人类形态。
- 她的行动让避难者安全抵达，但她并未亲眼看到结果，亦未听见为归来而敲响的晚钟。
- 几百年后，现世玩家依照赤月已有的血晶与满月觉醒流程唤醒刀灵，与她一起走到旧教堂，发现刻有“朝雾纱夜”的剑架和登记册。
- 玩家无法改变当年的结局，只能让现在的赤月知道：那些人平安回来了，钟也敲响过。两人再次听见钟声，并继续各自的现世旅程。

**主题**：归来、陪伴、守约；过去不必被“纠正”，现在的人仍可以回应过去的人。

## 已倾向保留的叙事选择

1. 赤月不应只是供玩家解锁伤害的战斗工具；她有独立性格、意愿与过往。
2. 纱夜**主动选择**与刀融合，不是被强行封印、更不是单纯等玩家解救。
3. 玩家属于**现世**；与纱夜的历史相隔数百年，不能穿越回去替代她或改变结局。
4. 纱夜应保留**活泼、会调侃、偶尔嘴硬**的一面；情感靠生活细节呈现，不靠反复哭诉。
5. 当前两篇将教堂设为曾经接纳难民的场所，红黑色来自后来的灾祸、焦痕和残存的红色彩窗；**暂不将其定义为专门的真名解放祭坛**。
6. 真名「朝雾纱夜」与现世名「赤月」可以共存：不是恢复“真正身份”后就否定共同战斗的岁月。
7. 暂不把其他主要角色的旧版剧情、师徒关系及相关地点绑定进本篇，以免妨碍后续重制。

## 时间线（草案）

- **旧时代，和平时期**：纱夜和旧刀一起生活，常去教堂；在登记册上写下名字与笨拙的小刀图案。
- **战争与撤离**：教堂成为避难所。纱夜接应最后四十三人，独自断后，旧刀折断。
- **满月之夜**：纱夜主动尝试古老的融合仪式，留下赤色刀刃，阻断追兵。
- **黎明及之后三天**：四十三人平安抵达；寻找无果，老妇人为他们及纱夜敲响晚钟，在册中留下记录。
- **漫长岁月**：教堂遭到后续战火破坏，历史失传，关于赤月的传承沉寂。
- **现世**：玩家锻刀、血晶刻铭、积累斩杀并在满月觉醒赤月；此后无意间来到旧教堂，找到记录、重新敲钟。

## 风格基调

以角色的细碎日常建立感情，再让同一件东西在两个时代呈现不同的意义：画歪的小刀、褪色红绳、登记册上缺失的圆圈、已经停止的钟。避免把世界观解释写成角色的长篇演讲。小说文字为原创，阅读风格定位是轻小说式的自然对话与克制抒情，不复制具体作品的语言。

## 核心意象

> 那一次，她没能回来。但这一次，有人回答了她。

“我们一起回去吧”在过去是少女对旧刀的邀请，在现世则成为赤月对玩家的邀请。
