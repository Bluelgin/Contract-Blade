# 赤月 · 女仆外观

适用：Minecraft 1.20.1、Forge、车万女仆 1.5.3 或更新兼容版本。
契约之刃首次启动会将随附模型安装到游戏目录的 tlm_custom_pack。无需安装 YSM。

可在车万女仆的模型菜单中选择「赤月 · 粉白」。安装 BladeTetra 并启用其契约之刃联动时，赤月觉醒创建的剑灵会默认使用此外观，显现后即可看到。已经觉醒的旧存档会补上默认外观；你自行选择的其他皮肤会保留，后续同步不会强制改回。

此模型不改变 BladeTetra 的觉醒条件，也不让普通同名武器获得剑灵；契约的手动呼唤、召回与共鸣规则仍然有效。

若自行安装了同一模型 ID 的赤月包，自动安装会跳过，不覆盖你的文件。发现重复模型时请移走旧的同名包并保留备份，然后重启游戏。
